# 07 最小二乘与非线性优化：优化不是魔法，它只是在当前猜测附近寻找更少矛盾的解释

> 前置：[三角化与局部地图](06-三角化与局部地图.md)。
>
> 本章目标：不预设高等数学熟练，讲清残差、平方和、权重、鲁棒核、线性化、雅可比、Gauss–Newton 与 Levenberg–Marquardt 到底在做什么。

## 1. 一个最小问题：三次测量都不一样，答案取什么

用尺子量一张桌子的长度，得到：

```text
1.01 米，0.99 米，1.02 米
```

我们要估计桌长 `L`。对第 `i` 次测量 `z_i`，残差定义为：

```text
r_i(L) = z_i - L
```

- `L`：我们正在尝试的桌长候选；
- `z_i`：第 `i` 次实际测量；
- `r_i`：该候选与测量之间的差。

若 `L = 1.00`：

```text
r_1 = 0.01
r_2 = -0.01
r_3 = 0.02
```

## 2. 为什么不直接让残差相加

直接相加时，正误差和负误差会抵消：

```text
0.1 + (-0.1) = 0
```

看似总误差为零，但两次都错了 0.1。

因此常最小化残差平方和：

```text
cost(L) = Σ r_i(L)²
```

- `Σ`：对全部测量求和；
- `cost`：代价，越小说明候选整体越能解释测量。

平方带来三个效果：

1. 正负残差不会互相抵消；
2. 大误差受到更强惩罚；
3. 函数光滑，便于求导和迭代。

这个简单问题的最小二乘答案正好是测量平均值 `1.0067 米` 左右。

## 3. SLAM 中只是把“桌长”换成了大量未知状态

视觉 SLAM 可能同时估计：

```text
相机位姿 T_1, T_2, ...
地图点 p_1, p_2, ...
IMU 速度 v_1, v_2, ...
IMU 零偏 b_g, b_a, ...
```

每条测量产生一项残差，例如：

- 地图点预测像素与实际像素之差；
- IMU 预测的两状态关系与当前状态估计之差；
- 激光点变换后到地图平面的距离；
- 回环预测的相对位姿与当前两帧位姿关系之差。

优化寻找一组状态，使所有可信残差的总成本尽量小。

## 4. 重投影残差再看一遍

世界地图点 `p_w_i`，当前相机位姿候选 `T_cw`：

```text
p_c_i = T_cw p_w_i
z_hat_i = project(K, p_c_i)
r_i = z_i - z_hat_i
```

- `z_i`：相机实际观察到的像素；
- `z_hat_i`：当前位姿和地图点预测的像素；
- `r_i`：二维像素残差。

优化可以只调整 `T_cw`，也可以同时调整 `T_cw` 和许多 `p_w_i`。调整对象叫决策变量或待估变量。

## 5. 为什么不同测量不能原样混加

假设同时有：

- 2 像素的视觉残差；
- 0.02 弧度的旋转残差；
- 0.1 米的平移残差。

这些单位不同，数值大小也不能直接表示可信度。通常使用加权平方：

```text
cost(x) = Σ r_i(x)ᵀ W_i r_i(x)
```

- `x`：把所有待估变量合在一起的状态；
- `r_i(x)`：第 `i` 条测量在状态 `x` 下的残差向量；
- `W_i`：第 `i` 条测量的权重矩阵；
- `r_iᵀ W_i r_i`：按方向和可信度缩放后的平方误差。

若某测量标准差较小、通常更准确，就应有更大权重；噪声较大的测量权重应更小。

一维情况下，如果测量噪声标准差为 `σ_i`：

```text
weight_i = 1 / σ_i²
```

- `σ_i`：测量典型波动大小；
- 方差是 `σ_i²`；
- 方差越大，权重越小。

权重不是“我更喜欢哪个传感器”的任性数字，应该尽量对应实际误差统计和单位归一化。

## 6. 最小二乘为什么能和概率联系起来

若假设测量误差服从零均值高斯分布，也就是小误差常见、大误差较少，那么寻找最可能状态，数学上会得到加权最小二乘形式。

第一遍不必推导概率密度。只需知道：

```text
噪声模型告诉系统每种残差多大算正常
权重把这种可信度写进优化目标
```

如果真实误差不是高斯小噪声，例如包含大量错匹配，普通最小二乘就会被大残差强烈拉动。

## 7. 一个离群值怎样拖走最小二乘

四次桌长测量：

```text
1.00, 1.01, 0.99, 5.00 米
```

前三个正常，最后一个显然是误读。普通平均值约为 `2.00 米`，完全偏离真实桌长。

原因是平方会重罚大误差，所以优化器会牺牲许多正确小残差，向离群值移动以减小那个巨大平方。

## 8. 鲁棒核不是删除所有大误差，而是限制其支配力

鲁棒代价常写成：

```text
cost(x) = Σ ρ(r_iᵀ W_i r_i)
```

- `ρ(...)`：鲁棒核函数，例如 Huber、Cauchy；
- 小残差区域近似保持平方代价；
- 大残差区域增长变慢，使单个异常值不至于支配全部优化。

以 Huber 直觉为例：

```text
残差小时：像平方一样认真精细拟合
残差很大时：惩罚近似线性增长，不让它无限放大话语权
```

鲁棒核也不是错匹配检测器。若多数匹配都错且彼此一致，或者阈值设置不当，它同样救不了系统。通常要与 RANSAC、语义/运动检查和优化后剔除结合。

## 9. 线性问题为什么容易，非线性问题为什么要迭代

若残差对未知量是直线关系：

```text
r(x) = ax - b
```

平方和最低点可通过一次线性方程求出。

但相机投影包含：

```text
X/Z、Y/Z、三维旋转
```

改变位姿后，像素位置不是随参数简单直线变化，因此是非线性问题。

非线性优化通常无法一步跳到答案，只能：

```text
从当前猜测 x 开始
      ↓
在附近用一个简单线性模型近似真实曲线
      ↓
求一个小修正 Δx
      ↓
更新 x ← x + Δx（位姿更新形式会略有不同）
      ↓
重新线性化，继续迭代
```

## 10. 线性化就是在脚边把弯路看成直路

考虑一维曲线：

```text
r(x) = x² - 4
```

我们想让 `r(x) = 0`，答案是 `x = ±2`。假设当前猜测 `x_0 = 3`。

在 `x_0` 附近，小改变量 `Δx` 下：

```text
r(x_0 + Δx) ≈ r(x_0) + J Δx
```

这里：

- `r(x_0) = 3² - 4 = 5`；
- `J = dr/dx = 2x`，在 `x_0 = 3` 时 `J = 6`；
- `J` 叫雅可比，在一维时就是斜率。

于是附近近似：

```text
r(3 + Δx) ≈ 5 + 6Δx
```

让近似残差等于零：

```text
5 + 6Δx = 0
Δx = -5/6 ≈ -0.833
```

更新：

```text
x = 3 - 0.833 = 2.167
```

还没精确到 2，但更近了。重新计算新的斜率再走一步，就会继续接近。

## 11. 雅可比矩阵到底是什么

当状态有许多分量、残差也有许多分量时，一维斜率变成雅可比矩阵：

```text
J_ij = 第 i 个残差对第 j 个状态变量的变化率
```

它回答：

> 如果把某个状态量稍微改一点，每个预测误差会朝哪个方向、改变多少？

例如一个像素残差有横纵两个分量，位姿小增量有 6 个分量，单个观测的雅可比可看作 `2×6`：

```text
两行：像素横向误差、纵向误差
六列：三维平移和三维小旋转
```

不需要第一遍手推所有元素，但要知道优化器依靠它决定“该往哪个状态方向修、修多少”。

## 12. Gauss–Newton 怎样从线性化得到修正量

把当前状态附近的残差近似为：

```text
r(x + Δx) ≈ r(x) + J Δx
```

希望找到 `Δx`，使近似残差平方和最小。会得到线性方程：

```text
H Δx = -g
```

其中：

```text
H = Jᵀ W J
g = Jᵀ W r
```

逐个解释：

- `Δx`：本轮要施加的小修正；
- `J`：残差对状态的雅可比；
- `W`：测量权重；
- `r`：当前残差；
- `H`：描述当前局部代价曲面弯曲和各变量耦合的矩阵近似；
- `g`：当前代价朝各状态方向变化的趋势。

求解线性方程得到 `Δx`，更新状态，再重新计算残差和雅可比。

工程代码通常解 `H Δx = -g`，而不是显式计算 `H⁻¹`。因为直接求逆更慢，数值稳定性也通常更差。

## 13. Levenberg–Marquardt 为什么给脚步加刹车

Gauss–Newton 的线性近似只在当前点附近可靠。若一步走太远，真实曲线可能和脚下直线差很多，代价反而上升。

Levenberg–Marquardt（LM）在方程中加入阻尼：

```text
(H + λI) Δx = -g
```

- `λ`：阻尼系数；
- `I`：单位矩阵。

直觉：

- 当前线性模型预测得好，就减小 `λ`，更大胆地用 Gauss–Newton 步；
- 当前一步不可靠，就增大 `λ`，缩小并稳定步长。

LM 仍是局部方法，不会因此自动找到全球最好答案。

## 14. 为什么初值如此重要

非线性目标可能像有多个山谷的地形：

- 从正确山谷附近开始，迭代会走向正确低点；
- 从很远或错误关联造成的山谷开始，可能收敛到错误局部最优；
- 初值太差时线性近似无效，甚至直接发散。

所以 SLAM 不是把所有东西交给优化器：

```text
运动模型/IMU 给初值
数据关联和 RANSAC 去明显外点
几何模型构造残差
非线性优化做局部精化
验收逻辑判断结果能否接受
```

每一层都不可少。

## 15. 旋转为什么不能一直普通相加

平移小增量可以直观写成：

```text
t_new = t_old + Δt
```

但三维旋转有特殊几何结构。直接给旋转矩阵 9 个元素各加一个数，会破坏它“轴仍互相垂直、长度为 1”的合法性。

常见做法是：

1. 用三维小向量 `δθ` 表示当前姿态附近的小旋转；
2. 通过指数映射把它变成合法小旋转 `Exp(δθ)`；
3. 与当前旋转相乘完成更新。

例如左乘更新：

```text
R_new = Exp(δθ) R_old
```

李群 `SO(3)、SE(3)` 和李代数的作用，就是让优化器在局部使用普通小向量，同时保证更新后的旋转和位姿仍合法。

第一遍知道这个动机即可，不必背指数映射公式。

## 16. 固定一个参考系为什么是必须的

若只有相对观测，把整条轨迹和地图一起平移或旋转，所有相对投影可能完全不变。单目还可以整体缩放。

这会让优化问题存在无法由测量决定的自由方向，矩阵 `H` 可能奇异。

常见处理：

- 固定第一帧位姿；
- 或给某个位姿加入先验；
- 单目初始化还要人为固定一个尺度，之后再用米制信息对齐。

这不是篡改答案，而是从许多等价坐标表达中选一个共同参考。

## 17. Hessian 很小的方向意味着什么

直觉上，`H` 描述代价曲面在各方向有多“硬”：

```text
某方向很硬：状态稍改，残差明显变大，测量对它约束强
某方向很软：状态改不少，残差也变化不大，测量难以区分
```

长走廊中，沿走廊方向可能比垂直墙面方向更软；单目整体尺度可能完全没有约束。

所谓退化和不可观，常会在数值上表现为某些方向信息很弱。求解器即使给出一个数字，也不代表该方向真的可信。

## 18. 优化结束的条件是什么

常见停止条件：

- 状态更新 `Δx` 已经很小；
- 代价下降已经很小；
- 梯度很小；
- 达到最大迭代次数；
- 新一步使代价变坏，策略决定停止或调整阻尼。

“求解器返回 success”通常只说明数值过程满足某个结束条件，不等于：

- 数据关联全正确；
- 模型与现实一致；
- 结果达到任务精度；
- 找到了全局最优。

## 19. 优化后必须做的现实验收

检查至少包括：

- 代价和残差分布是否合理；
- 是否只靠少量点支撑；
- 内点是否覆盖足够视野；
- 状态更新是否出现不合理突跳；
- 深度和速度是否物理合理；
- 传感器间残差是否长期有方向性偏差；
- 留出的验证数据是否也能被解释；
- 系统是否在退化场景中虚假自信。

如果所有像素残差都朝图像同一方向偏，可能不是位姿随机误差，而是时间同步、内参或外参有系统问题。

## 20. 从最小二乘到后续所有章节

后面不同算法只是更换：

```text
状态变量是什么
测量是什么
预测模型是什么
残差怎样定义
权重怎样给
哪些变量一起优化
历史保留多长
```

例如：

| 问题 | 状态 | 残差 |
|---|---|---|
| PnP 精化 | 当前相机位姿 | 重投影误差 |
| 局部 BA | 多个位姿 + 地图点 | 多帧重投影误差 |
| 视觉惯性优化 | 位姿、速度、零偏、地图点 | 视觉残差 + IMU 残差 |
| 激光配准 | 当前位姿 | 点到面/分布残差 |
| 位姿图优化 | 许多关键帧位姿 | 相对位姿约束误差 |

## 21. 一段不带矩阵的伪代码

```text
x = 初始状态

重复：
    根据 x 预测每条测量
    计算实际测量与预测的残差
    拒绝明显错误数据，并按可信度加权
    计算“状态稍微变化会怎样改变残差”
    求出一个让总残差下降的小修正
    尝试更新 x
    若变好则接受，否则缩小步子或拒绝

输出 x_hat，并进行物理与统计验收
```

这就是非线性最小二乘的骨架。

## 22. 本章最小结论

1. 残差是实际测量与当前状态预测测量之间的差。
2. 最小二乘寻找能让许多可信证据总体少冲突的状态。
3. 权重描述不同残差尺度和可信度，鲁棒核限制异常大残差的支配力。
4. 非线性优化在当前猜测附近线性化，求小修正并反复迭代。
5. 雅可比描述状态小变化如何影响残差；`H Δx = -g` 给出本轮更新。
6. 初值、数据关联、模型和验收与求解器同样重要。
7. 优化得到的是当前模型和数据下的局部估计，不是现实真值认证。
