# SLAM 全书初学者可读性审查：不只解释名词，还要让问题一步步长出来

> 本文是维护记录，不属于第一遍必读主线。
>
> 审查目标：一个数学和物理知识已经生疏的读者，能否从机器人现实困难出发，理解每个概念为何出现、拿什么证据、估计什么、哪里会错，又怎样进入下一章。

## 1. “符号都解释了”为什么仍然可能看不懂

下面这句话即使解释了 `E、R、t` 的定义，也很容易让初学者失去主线：

```text
E = [t]×R，匹配点满足 x₂ᵀEx₁ = 0
```

真正需要先发生的是：

```text
一个单目像素只能给一条射线
→ 第二次观察给另一条射线
→ 两条射线和两个相机中心位于同一平面
→ 平面内向量与法向量点积为零
→ 才出现对极约束和本质矩阵
```

所以审查不只问“术语是否有字典定义”，还要问：

1. 现实中的困难是否先出现；
2. 读者已经会的办法为什么不够；
3. 新概念解决主线中的哪一处缺口；
4. 公式中的量来自测量、标定、当前估计还是人为先验；
5. 输出是候选、局部最优、已验收结果还是现实真值；
6. 它怎样交给下一模块，又会在什么场景失败。

## 2. 全书统一审查标尺

### 2.1 先出现机器人困难，再出现缩写

不能因为附录有缩写表，就在正文连续列出 `PnP、BA、NDT` 而不说它们为什么需要。缩写第一次进入主线时，要给英文全称或至少给足够明确的人话职责；专章再展开细节。

### 2.2 固定三类对象

每章都要区分：

```text
现实：x_real、m_real，真机通常无法完整读取
证据：图像、点云、IMU、轮速等测量 z
估计：轨迹 x_hat、地图 m_hat 及其不确定性
```

算法更新估计，不是修改现实，也不是从测量中直接读取真值。

### 2.3 坐标和时间必须原地说明

三维数字必须回答相对于谁；变换必须能念成“把谁变到谁”；测量必须说明属于哪个时刻。外参和时间偏移不能被当作实现细节藏到最后。

### 2.4 数据关联必须先于精密几何

公式成立的前提是对应关系正确。每个位姿算法都要说明匹配从哪里来、怎样剔除外点、错关联为何危险。

### 2.5 先讲残差在比较什么，再讲求解器

`Gauss–Newton、LM、Schur` 不能先于“实际测量与当前预测为何不一致”出现。读者首先要知道状态稍微改变会怎样改变误差。

### 2.6 明确可观性和退化

纯旋转、视差过小、长走廊、单平面和运动激励不足，都是证据本身缺少某些方向的信息。正文不能暗示换一个更强求解器便能凭空恢复。

### 2.7 第一遍与第二遍分层

第一遍必须保留现实问题、证据、未知量、输出和失败边界；矩阵分解、李群推导、预积分雅可比和稀疏求解细节可放到第二遍或专题。

### 2.8 算法必须长成持续系统

两帧计算之后还要说明预测、局部地图、关键帧、状态机、跟踪丢失、重定位、线程和队列。一次算对不等于机器人能持续运行。

### 2.9 地图和指标必须回到任务

地图不以“点多、截图漂亮”为唯一目标；轨迹也不以一个 ATE 数字概括全部质量。必须回答下游怎样查询、延迟多少、失败能否发现。

## 3. 全书唯一叙事

```text
00：机器人为何必须同时估轨迹和地图
01：所有位置数字先说明相对于谁
02：传感器只给局部、带误差的测量证据
03：单目投影为什么天然丢失深度
04：两次观测中谁和谁来自同一现实结构
05：已知对应两端是二维还是三维，决定能估什么运动
06：不同视角怎样逐渐约束深度并形成局部地图
07：许多带噪声证据怎样通过残差联合修正
08：单次几何怎样成为不断预测、跟踪、验收和恢复的前端
09：IMU 怎样填补图像间隙，又为什么必须由视觉纠漂
10：后端怎样把位姿、地图点和多传感器约束画成图并修改历史
11：回到旧地方时，怎样先提出候选、再几何验证、最后全局修正
12：轨迹一致以后，地图应为定位、规划、避障或理解保留什么
13：换成激光距离点后，同一估计主线怎样继续成立
14：时间、坐标、算力、日志和指标怎样决定系统能否真正交付
```

每章末尾都明确把当前输出交给下一章，避免教材变成 15 个互不相干的算法名词。

## 4. 逐章审查结果

| 章 | 固定问题 | 新概念为什么出现 | 第一遍必须带走 |
|---|---|---|---|
| 00 | 陌生楼内无 GPS、无地图 | 定位依赖地图，建图又依赖位姿 | 测量 `z` 不是真值，输出 `x_hat、m_hat` 仍可修正 |
| 01 | 同一个杯子被不同人给出不同坐标 | 所有观测要放进共同参考 | `T_ab` 把 `b` 表达变到 `a`，轨迹是一串位姿 |
| 02 | 各传感器说的话不同且不完整 | 需要测量模型、标定、时间戳和误差分类 | 相机、激光、IMU、轮速各自直接测什么、不测什么 |
| 03 | 一个像素无法唯一恢复三维点 | 投影、内参、外参、深度、双目与尺度自然出现 | `u=f_xX/Z+c_x`；单目像素是一条射线 |
| 04 | 两张图没有现实物体编号 | 检测、描述、光流、直接法、几何验证和 RANSAC 出现 | 外观匹配只给候选，错关联不是普通小噪声 |
| 05 | 对应两端可能只有像素，也可能有深度 | 2D–2D、PnP、ICP 分工由已知信息决定 | 先数清两端维度；所有结果都需要关联和退化验收 |
| 06 | 两条有噪声射线并不精确相交 | 三角化、视差、关键帧、点生命周期和局部地图出现 | 视差小会让深度脆弱，算出数值不等于点已成熟 |
| 07 | 同一地图中许多证据互相有小冲突 | 残差、权重、鲁棒核、线性化和雅可比出现 | 优化是在当前猜测附近找更少矛盾的解释，不是事实认证 |
| 08 | 第三帧以后系统还要持续工作 | 预测、局部地图、关键帧、跟踪状态和重定位出现 | 前端必须知道何时跟丢，不能只发布一个无质量数字 |
| 09 | 图像低频且快速运动时初值差 | IMU 状态、零偏、重力、预积分和可观性出现 | IMU 短时预测、视觉长期纠正；外参与时间错误会冒充状态误差 |
| 10 | 当前残差可能来自当前位姿、旧位姿或地图点 | BA、因子图、位姿图、滑窗和边缘化出现 | 变量是估计，因子由测量、关联、模型和权重共同组成 |
| 11 | 相邻里程计无法自己知道终点就是起点 | 词袋/全局描述、几何验证、回环边和地图融合出现 | 地点识别只提候选，假回环会让全局优化毁图 |
| 12 | 定位、规划和展示对地图要求不同 | 稀疏点、占据、TSDF、ESDF、语义和子地图出现 | 未知不等于自由，地图表示由下游查询反推 |
| 13 | 激光有距离，却仍无全局位姿 | 去畸变、ICP、NDT、LIO 和激光回环出现 | 视觉和激光共享测量—关联—残差—地图—后端主线 |
| 14 | 数据集成功不等于真机可用 | 坐标树、同步、线程、日志、ATE/RPE 和项目阶段出现 | 可靠系统必须知道自己何时不知道，并向下游传递时间与质量 |

## 5. 公式审查底线

每个关键公式至少回答：

1. 左边是什么，单位和坐标系是什么；
2. 右边每个量从传感器、标定、当前估计还是固定模型而来；
3. 哪些量已知，哪些是优化变量；
4. 这是现实关系、预测测量、残差还是状态更新；
5. 在什么运动或场景下它会失效或变弱；
6. 结果是候选、局部最优还是经过系统验收的输出。

全书反复使用：

```text
(x_real, m_real)
→ 现实产生测量 z
→ 当前估计 (x_hat, m_hat) 预测 z_hat
→ 残差 r = z - z_hat
→ 根据数据关联、权重和模型修正估计
→ 新测量到来后继续循环
```

`r` 小不自动证明估计正确，因为错误关联、错误模型和不可观方向也可能产生看似不错的残差。

## 6. 允许第二遍再学什么

允许第一遍跳过：

- `SO(3)、SE(3)` 指数与对数映射的精确公式；
- 五点法、八点法和本质矩阵 SVD 分解细节；
- Gauss–Newton 正规方程的完整矩阵推导；
- Schur 补的分块消元公式；
- IMU 预积分全部雅可比和噪声传播；
- 边缘化先验的一致性高级处理；
- NDT、ESDF 等具体数据结构实现。

不允许推迟到第二遍：

- 一个量从哪里来；
- 它相对于哪个坐标系、属于哪个时刻；
- 为什么当前证据能约束它；
- 它是现实、测量、估计还是预测；
- 哪些信息当前根本不可观；
- 输出怎样进入下一模块以及怎样报告失败。
