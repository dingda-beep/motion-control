# SLAM：给机器人工程师的从零教程

这套教程写给数学和概率基础可能已经生疏，但愿意顺着一个真实问题慢慢理解的读者。

它不从李群、对极几何、BA 和因子图的名词清单开始，而是始终追踪一台刚开机的移动机器人：

> 它不知道自己在世界的哪里，也没有现成地图；它只能不断收到图像、激光、IMU 和轮速等带噪声的局部证据。它怎样在运动中逐渐判断“我在哪里”和“这个世界长什么样”？

这就是 SLAM 的主问题。

## 从这里开始

第一次阅读请先打开：[导读：知识地图与三遍阅读法](导读.md)。

然后按下面的第一遍主线读：

```text
00 SLAM 在解决什么
→ 01 怎样表示“我在哪里”
→ 02 传感器到底给了什么证据
→ 03 相机为什么会丢失深度
→ 04 两帧中的哪些观测属于同一个地方
→ 05 怎样由对应关系推断相对运动
→ 06 深度和局部地图怎样逐渐出现
→ 07 许多带噪声、互相矛盾的证据怎样一起纠错
→ 08 前端怎样持续跟踪而不是只算两帧
→ 09 IMU 怎样在图像之间帮助预测
→ 10 后端怎样联合修正轨迹和地图
→ 11 回到旧地方时怎样承认并纠正长期漂移
→ 12 为什么不同任务需要不同地图
→ 13 激光 SLAM 和视觉 SLAM 的本质怎样统一
→ 14 一套真实 SLAM 系统怎样校准、同步、评估和排错
```

## 全书的唯一主线

```text
未知的真实轨迹 x_real 和真实环境 m_real
                ↓ 在现实中产生测量
       图像 / 激光 / IMU / 轮速 z
                ↓ 时间同步、标定和预处理
             当前证据
                ↓ 数据关联：哪些证据来自同一物体或地点
       前端估计短时运动与局部结构
                ↓
       后端用更多历史约束联合纠错
                ↓
       输出轨迹估计 x_hat 与地图估计 m_hat
                ↓
      为导航、避障、规划、建图或人机交互服务
```

SLAM 不是先定位完，再建图；也不是先建完图，再定位。两者互相依赖：

```text
位姿估得更好 → 同一地点的多次观测更能放在一起 → 地图更一致
地图更可靠   → 新观测更容易找到自己应该对齐哪里 → 位姿更准
```

这个相互依赖，正是 Simultaneous Localization and Mapping（同时定位与建图）中“同时”的真正含义。

## 与《视觉 SLAM 十四讲》的关系

本教程参考了高翔等著《视觉 SLAM 十四讲：从理论到实践》的知识范围，也核对了作者公开的[第二版配套代码仓库](https://github.com/gaoxiang12/slambook2)。

这里的组织方式不是原书摘录或章节缩写，而是按本仓库运控教程的写作经验重新组织：

- 从真实因果链引出概念，不用术语列表开场；
- 相机、激光、IMU 都被看成对同一隐藏世界的不同证据；
- 数学只在现实问题需要时出现，符号在原地解释；
- 始终区分真实状态、传感器测量、模型预测、优化候选和最终估计；
- 不只讲一次算法“算对”，还要讲持续系统怎样失败、恢复和验收。

知识范围的重新编排如下。它不是逐章摘要，而是说明原书的重要主题在本教程主线中的落点：

| 《十四讲》配套内容中的主题 | 本教程落点 | 为什么重新放在这里 |
|---|---|---|
| SLAM 总览 | 00、导读 | 先建立“现实—测量—估计”世界观 |
| 三维刚体运动、李群 | 01、07、附录 A | 先会读坐标变换；到需要优化小增量时再引出李群 |
| 相机与图像、双目/RGB-D | 02、03 | 先分清传感器测量，再推投影与深度 |
| 非线性优化 | 07 | 从测桌长的残差开始，再进入雅可比和 Gauss–Newton |
| 特征视觉里程计、对极几何、PnP、三角化 | 04～08 | 按“先关联、再估运动、再长出地图、最后组成持续前端”展开 |
| 光流与直接法 | 04、08 | 和特征法放在同一数据关联/跟踪问题下比较 |
| BA、位姿图 | 10 | 统一为变量和测量因子的历史联合纠错 |
| 回环检测 | 11 | 强调外观候选、几何验证和全局修正是三件事 |
| 稠密建图 | 12 | 由导航、规划、定位和展示任务反推地图表示 |
| 完整视觉里程计工程 | 08、14 | 将算法主循环与同步、线程、日志、评估和失效恢复合并验收 |

另外增加第 09 章视觉惯性融合和第 13 章激光 SLAM，使相机、IMU、激光和轮速都能落回同一个估计框架，而不是把 SLAM 误解成只属于相机的算法。

## 文档约定

- 公式使用普通 Markdown 可显示的纯文本形式；
- 每个新符号紧邻它第一次出现的位置解释；
- 同一个变换必须说清“把谁的坐标变到哪个坐标系”；
- 第一遍允许跳过李群、雅可比、Hessian 和预积分细节，但不允许跳过它们要解决的现实问题；
- 算法输出的是估计与候选，不是现实世界被程序“读出来”了；
- 每章结尾必须回答：它为主线增加了哪一段能力，又没有解决什么。

本教程还保留一份面向后续维护的[全书初学者可读性审查](全书初学者可读性审查.md)。它不属于第一遍必读内容，用来防止以后修改时重新出现“缩写提前出现、符号有定义但问题没长出来、算法结束后没有回到真实系统”等断点。
