# 12 地图表示与机器人任务：地图不是世界的复制品，而是为某种任务保留的信息

> 前置：[回环检测与重定位](11-回环检测与重定位.md)。
>
> 本章目标：理解稀疏点、点云、栅格、体素、TSDF、ESDF、网格和语义地图分别回答什么问题，以及为什么“更稠密”不等于“更有用”。

## 1. 同一个房间为什么需要许多种地图

面对同一个房间：

- 相机定位只需稳定的角点和描述子；
- 扫地机器人要知道平面哪里被占据、哪里可通行；
- 无人机要知道三维空间中离障碍还有多远；
- 机械臂要知道桌面和杯子的精确表面与姿态；
- 人想看重建效果，希望有彩色纹理和连续表面。

没有一种地图在所有维度上同时最好。地图是一种信息选择：

> 从连续、复杂、不断变化的现实中，保留当前任务真正需要的结构，并接受相应的信息损失和计算成本。

## 2. 地图至少承担三种不同角色

### 定位地图

让传感器能够重新找到自己。要求元素稳定、可重复观测、易建立对应。

### 规划地图

让规划器判断哪里可走、哪里危险、离障碍多远。要求空间占据和自由区域可靠。

### 展示/理解地图

让人或高级任务理解环境，例如彩色表面、物体类别、房间拓扑。

一张地图可以同时承担多种角色，但必须明确哪些层是给谁用的。

## 3. 稀疏特征点地图

视觉特征 SLAM 常保存少量三维地图点、描述子和观测关系：

```text
地图点位置 + 哪些关键帧看见它 + 局部外观描述
```

优点：

- 数据量小；
- 投影匹配和 BA 高效；
- 很适合相机定位和回环。

缺点：

- 点之间空白不代表自由空间；
- 不能直接告诉机器人墙面是否可穿过；
- 不适合直接碰撞检测和稠密表面展示。

一个只有几千个点但能稳定重定位的地图，对视觉 SLAM 可能比几百万个噪声点更有价值。

## 4. 点云地图

点云保存许多三维点，可带颜色、强度、法向等属性。

优点：

- 接近深度或激光原始几何；
- 易于可视化；
- 可用于点云配准和表面分析。

缺点：

- 点是表面采样，不直接表达点之间是否连续；
- 没有点的地方可能是自由空间、未观测区域或传感器盲区；
- 多帧重复点导致体量快速增长；
- 漂移和动态物体会产生重影。

因此点云地图常需要下采样、滤波、动态剔除和空间索引。

## 5. 二维占据栅格

把地面平面划成许多小格，每格表示：

```text
被障碍占据 / 可通行自由 / 尚未观测
```

注意“自由”和“未知”不能混：

- 自由：传感器射线穿过这里且未遇到障碍；
- 未知：传感器从未可靠看过这里。

二维激光射线击中墙时，可把：

- 传感器到击中点之前穿过的格子更新为更可能自由；
- 击中点所在格子更新为更可能占据。

多次观测使用概率或 log-odds 累积，而不是一次测到就永久写死。

### 分辨率的交易

```text
格子小：细节多、内存和更新成本高、对位姿噪声敏感
格子大：计算省，但窄门和小障碍可能被抹掉
```

分辨率应由机器人尺寸、定位精度和规划需求共同决定。

## 6. 三维体素地图

Voxel（体素）是三维格子，相当于立体像素。每个体素可保存：

- 占据概率；
- 表面距离；
- 颜色；
- 语义类别；
- 观测次数和时间。

完整均匀三维网格非常耗内存，因此常用八叉树、哈希表或分块结构只存被访问区域。

## 7. TSDF：在表面附近保存带符号距离

TSDF 全称 Truncated Signed Distance Function，截断有符号距离函数。

对空间中一个体素，保存它到最近表面的近似有符号距离：

- 表面一侧为正；
- 另一侧为负；
- 表面附近为零；
- 超过一定距离后截断，不再关心精确远距离。

符号正负约定可因实现不同而反，但零交叉代表表面。

多帧深度从不同角度融合到 TSDF 后，随机深度噪声可以被平均，零等值面可提取成较平滑网格。

TSDF 擅长表面重建，但体素中保存的值通常只在已观测表面附近有意义，不等于任意位置到全局最近障碍的距离。

## 8. ESDF：规划器更关心“离最近障碍多远”

ESDF 全称 Euclidean Signed Distance Field，欧氏有符号距离场。

它给空间每个位置保存到最近障碍表面的欧氏距离。规划器可直接问：

```text
当前位置离最近障碍多远？
往哪个方向走会更远离障碍？
```

因此 ESDF 很适合轨迹优化和碰撞代价计算。

常见关系：

```text
深度/点云 → 占据或 TSDF 融合 → 更新 ESDF → 供规划使用
```

TSDF 与 ESDF 都有“距离”，但服务对象和距离定义不同，不能只因缩写相似就混用。

## 9. 网格地图 Mesh

网格用顶点、边和三角面片表示连续表面。

优点：

- 比原始点云更明确地表达表面连通；
- 适合渲染、测量和物体几何；
- 可从 TSDF 零等值面提取。

缺点：

- 在线增量更新和拓扑修补较复杂；
- 错误位姿会造成表面撕裂或重复；
- 对导航仍可能要转为占据或距离场。

## 10. 高程图与可通行性地图

地面机器人未必需要完整三维体素。可在二维网格中保存每格地面高度、坡度、粗糙度和障碍高度：

```text
位置 (x,y) → 地面高度 z + 地形属性
```

这类 2.5D 地图适合腿足机器人或户外车判断落脚与通行，但不能自然表达桥下和桥上这类同一 `(x,y)` 有多个表面的场景。

## 11. 语义地图

语义地图给几何元素附加含义：

- 这是墙、门、桌子还是人；
- 这是可移动椅子还是永久建筑结构；
- 这个房间是厨房还是走廊；
- 某个物体实例是否与之前相同。

语义可以帮助：

- 过滤动态物体；
- 以物体为目标进行导航和交互；
- 建立更紧凑的对象级地图；
- 跨视角或外观变化重定位。

但语义网络也会误识别，不能自动变成几何真值。类别、实例身份、三维位置和持续时间都需要不确定性管理。

## 12. 拓扑地图

拓扑地图不追求每厘米几何，而保存地点和连通关系：

```text
办公室 A --走廊-- 电梯厅 --门-- 办公室 B
```

它适合大范围任务规划和地点级导航，数据紧凑。机器人仍可能需要局部度量地图完成避障和精确控制。

实际系统可组合：全局拓扑图选择路线，局部几何地图避障。

## 13. “地图越密越好”为什么是错的

更密意味着：

- 更多存储、传输和更新成本；
- 更容易累积动态物体和重复表面；
- 对位姿误差更敏感，重影更明显；
- 下游可能还要再降采样；
- 不一定增加定位所需的可重复特征。

真正的问题应是：

```text
这个表示能否在目标速度和资源下，可靠回答下游问题？
```

## 14. 地图坐标更新为什么很棘手

回环会修改历史位姿。若稠密点云只是把每帧点永久变换到世界坐标后丢在一起，历史点已经失去与原关键帧的联系，很难跟随轨迹修正。

可选设计：

- 保存每个子地图或关键帧的局部点云，回环后只更新其位姿；
- 使用可变形地图或重新融合原始深度；
- 将全局地图拆成多个局部一致子地图；
- 保留足够原始数据，必要时离线重建。

地图数据结构必须预先考虑后端会改历史，而不是把第一次世界坐标投影当永久真值。

## 15. 子地图为什么常用

长时间建图可分为若干局部子地图：

- 每个子地图内部在短时间内较一致；
- 子地图之间通过位姿图连接；
- 回环主要调整子地图整体位姿；
- 局部查询和更新规模受控。

二维栅格 SLAM、激光 SLAM和稠密三维建图中都能看到这种思想。

## 16. 动态世界怎样进入地图

现实并非静态：人会走、椅子会挪、门会开关、树叶会动。

简单把每次观测永久累积，会产生鬼影。处理层次包括：

- 短时滤波：要求多次稳定观测才写入；
- 射线清除：新观测表明原占据位置已变成自由；
- 语义动态类别屏蔽；
- 估计物体独立运动；
- 保存时间戳、观测次数与最后见到时间；
- 分离长期静态层和短期障碍层。

导航通常需要“长期背景地图 + 实时局部障碍”共同工作。

## 17. 未知、自由和占据为什么必须分开

机器人没看过一扇门后面的空间，不能因为点云里没有点就认为那里自由。

```text
没有点 ≠ 没有障碍
```

只有传感器射线可靠穿过某区域，才有自由空间证据。遮挡后方仍应保持未知。

这个区别直接影响规划安全：激进规划器可能允许进入未知区域，保守规划器则把未知视作不可通行。策略应由任务设定，而不是地图格式偷偷决定。

## 18. 地图质量怎样评价

不能只看截图。应结合用途：

### 定位地图

- 重定位成功率；
- 位姿精度和稳定性；
- 地图跨时间变化后的可用性；
- 存储和查询速度。

### 占据/规划地图

- 障碍漏检与误检；
- 自由、占据、未知分类；
- 窄通道是否保持；
- 规划成功率和碰撞余量；
- 更新延迟。

### 表面重建

- 点到真实表面的距离；
- 完整度；
- 重复面和孔洞；
- 细节与噪声；
- 动态物体残留。

一张视觉上光滑的地图可能把窄障碍抹掉；一张有噪点的图也可能仍足以定位。评价必须回到任务。

## 19. 从下游任务反推地图设计

设计前回答：

1. 下游查询是什么：最近障碍、可通行性、特征匹配、表面还是物体？
2. 查询频率和最大延迟是多少？
3. 需要二维、2.5D 还是三维？
4. 可接受的空间分辨率和定位误差是多少？
5. 未知空间如何处理？
6. 环境变化多快，旧信息何时失效？
7. 回环后地图怎样跟随位姿更新？
8. 内存、计算和网络预算是多少？

这比先选“最先进地图格式”更接近工程本质。

## 20. 本章最小结论

1. 地图是为任务保留的信息模型，不是现实世界的无损复制。
2. 稀疏点适合视觉定位，点云适合几何展示与配准，栅格适合占据与通行判断。
3. TSDF 适合融合表面，ESDF 适合查询到最近障碍的距离。
4. 没观测到不等于自由；未知、自由、占据必须分开。
5. 回环会修改历史位姿，地图结构应支持子地图变换、重新融合或一致更新。
6. 地图质量必须用下游任务成功率和误差衡量，而不是只看是否稠密漂亮。
