# 13 激光 SLAM 与扫描匹配：从像素射线换成距离点，估计主线并没有改变

> 前置：[地图表示与机器人任务](12-地图表示与机器人任务.md)。
>
> 本章目标：理解扫描匹配、ICP、NDT、特征激光里程计、扫描去畸变和激光惯性融合，并能把它们映射回前面统一的 SLAM 因果链。

## 1. 激光比相机多知道距离，但没有直接知道全局位姿

一束激光测量可简化为：

```text
角度/方向 d_l + 距离 r + 时间 t
```

在激光坐标系中得到点：

```text
p_l = r d_l
```

这比单目像素多了沿射线的距离，因此单帧就能形成有米制尺度的局部几何。

但要放进世界地图仍需：

```text
p_w = T_wl(t) p_l
```

- `p_l`：点在激光坐标系中的坐标；
- `T_wl(t)`：测量时刻激光到世界的位姿；
- `p_w`：点在世界坐标系中的坐标。

`T_wl(t)` 正是 SLAM 要估计的状态之一。

## 2. 一帧“扫描”可能不是同一时刻

机械旋转激光一圈需要时间。每个点具有自己的采样时刻：

```text
p_l(t_1), p_l(t_2), ..., p_l(t_n)
```

机器人运动时，严格变换应分别使用：

```text
p_w(t_i) = T_wl(t_i) p_l(t_i)
```

如果假装整圈都属于结束时刻 `t_n`，快速转弯时直墙会扭曲。

扫描去畸变（deskew）使用扫描期间的连续运动估计，把所有点补偿到同一参考时刻。

## 3. 2D 激光扫描匹配

二维激光给平面内许多距离点。新扫描到来时，寻找平面位姿：

```text
(x, y, θ)
```

使当前扫描与上一扫描或已有栅格/子地图尽量对齐。

两种常见模式：

### Scan-to-Scan

当前扫描对齐上一扫描。速度快，但误差像链条一样累积。

### Scan-to-Map

当前扫描对齐局部地图或子地图，使用更稳定的多帧结构，通常更抗单帧噪声。

这与视觉“帧间跟踪”和“局部地图跟踪”的区别完全对应。

## 4. ICP 的核心循环

ICP（Iterative Closest Point，迭代最近点）求两组点之间的刚体变换。

```text
给定当前位姿初值
      ↓
把当前点云变换到目标地图附近
      ↓
为每个点寻找目标对应点/平面
      ↓
最小化对应残差，更新位姿
      ↓
重新建立对应，继续迭代
```

它把数据关联和位姿优化交替进行。

## 5. 点到点 ICP

对应点为：

```text
p_i ↔ q_i
```

寻找 `R、t` 使：

```text
r_i = q_i - (R p_i + t)
```

总成本：

```text
Σ ||r_i||²
```

它要求变换后的源点靠近目标点。点云采样位置在表面上可能并不一一相同，所以即使两个扫描看到同一面墙，也未必存在真正同位置的采样点。

## 6. 点到平面 ICP

目标点 `q_i` 附近估计单位法向 `n_i`。残差只取变换点到局部平面的法向距离：

```text
r_i = n_iᵀ (R p_i + t - q_i)
```

如果一个点沿墙面方向稍有错位，并不影响它仍在墙面上；点到平面误差不会过度惩罚切向差异，因此在稠密表面上通常比点到点更有效。

但法向估计需要足够邻域和合适点云质量，边缘、稀疏区和混合表面会使法向不可靠。

## 7. 对应关系为什么仍是 ICP 的薄弱环节

最近点不等于同一现实表面：

- 初值差时，地面点可能配到墙；
- 两根相似柱子可能配错；
- 动态车辆产生临时最近点；
- 遮挡使两帧可见表面不同；
- 点密度不均导致许多源点挤向同一区域。

常见防线：

- 最大对应距离；
- 法向夹角检查；
- 反射强度或语义一致性；
- 鲁棒核和残差剔除；
- 多分辨率从粗到细；
- IMU/轮速提供好初值；
- 检查匹配几何覆盖和退化。

## 8. NDT 在做什么

NDT（Normal Distributions Transform，正态分布变换）把目标点云空间划成网格，在每个有足够点的格子中估计局部分布：

```text
均值 μ + 协方差 Σ
```

当前点变换后落入某格子，检查它在该局部分布下有多合理。优化位姿，让当前点更符合地图分布。

直觉上：

```text
ICP：当前点应该靠近某个目标点或平面
NDT：当前点应该落在目标局部点分布的高概率区域
```

NDT 避免每轮为每点显式寻找唯一最近点，并且目标函数可较平滑；但网格大小、点密度、初值和退化场景仍决定结果。

## 9. 激光特征法为什么选择边缘和平面

三维激光扫描中，有些方法根据局部曲率选：

- 边缘特征：邻域形状变化大；
- 平面特征：邻域近似平面。

当前边缘点与地图边线建立点到线残差，平面点与地图平面建立点到面残差。

这样可以：

- 用较少有结构的点减少计算；
- 根据几何类型构造更有意义的残差；
- 避免把整帧所有噪声点都同等使用。

它和视觉特征法都在选择可重复、能约束运动的证据，但“特征”的物理含义不同。

## 10. 几何退化：残差很小，也可能有方向没被约束

### 长直走廊

两侧墙面强约束横向位置和朝向，却可能较弱约束沿走廊方向的位置。

### 单一平面

只看一大片平墙，点到面误差能约束法向方向，却很难约束沿墙面平移和绕法向旋转。

### 对称结构

重复柱子或隧道截面可能让多个位姿都产生相似配准分数。

因此不能只看 ICP 最终平均误差。应分析优化矩阵的特征值、有效几何方向、点分布，并结合 IMU 或其他传感器补足弱方向。

## 11. 激光里程计的持续主循环

```text
接收带逐点时间的扫描
      ↓
使用 IMU/运动预测进行扫描去畸变
      ↓
滤波、下采样、提取点/线/面证据
      ↓
用预测位姿把当前扫描放到局部地图附近
      ↓
建立点到点/线/面/分布关联
      ↓
优化当前位姿并验收退化与残差
      ↓
必要时加入关键帧和局部子地图
      ↓
后端加入里程计边、回环边与其他因子
```

它和视觉前端的结构几乎一一对应。

## 12. 下采样为什么不是简单丢精度

激光一帧可有数万到数十万点。体素下采样把同一小体素内的点用代表点替代：

- 限制计算量；
- 让点密度更均匀；
- 减少近处过密区域支配优化；
- 与地图所需分辨率匹配。

体素太大，会抹掉细杆和边缘；太小则计算昂贵且保留大量冗余。仍要由传感器噪声、场景尺度和任务需求决定。

## 13. 局部子地图怎样维护

常见策略：

- 只保留附近若干关键帧点云；
- 将点插入体素哈希或 KD-tree 等空间索引；KD-tree 是一种按空间位置组织点、便于快速寻找邻近点的数据结构；
- 删除超出局部范围的点；
- 保留每个子地图的局部坐标，在全局回环时只修正子地图位姿；
- 动态或长期不稳定点降低权重或不写入。

局部地图太小，几何不够稳定；太大，查询变慢且旧误差、动态物体更多。

## 14. LIO：激光惯性里程计为什么很强

LIO（LiDAR-Inertial Odometry）联合激光和 IMU：

```text
IMU 高频传播位姿、速度和零偏
      ↓
为整帧激光每个点提供运动补偿
      ↓
激光与地图配准修正惯性漂移
      ↓
修正后的状态成为下一次传播起点
```

IMU 不只给配准初值，还解决扫描期间每个点位姿不同的问题；激光的几何约束又帮助估计 IMU 零偏和长期运动。

## 15. 紧耦合 LIO 的状态与残差

典型状态可能包含：

```text
位姿 R,p
速度 v
陀螺零偏 b_g
加速度零偏 b_a
重力方向或相关参数
可选激光-IMU 外参和时间偏移
```

测量约束包括：

- IMU 传播/预积分残差；
- 当前激光点到局部地图平面的残差；
- 可选轮速、GNSS、高度等因子。

可用迭代滤波或滑窗优化组织它们。名称不同，核心仍是测量预测与实际证据之间的残差。

## 16. 激光回环怎样做

候选检索可以使用：

- 扫描全局描述子；
- 子地图几何摘要；
- GNSS 或已有位置先验；
- 视觉辅助地点识别。

候选仍需点云配准验证，检查重叠率、残差、几何覆盖和变换合理性。接受后加入位姿图回环边，优化关键帧或子地图位姿。

激光也会感知混淆：不同楼层的相似走廊、重复隧道和仓库货架都可能产生假回环。

## 17. 视觉与激光 SLAM 的统一对应表

| 主线环节 | 视觉 | 激光 |
|---|---|---|
| 原始证据 | 像素亮度/颜色 | 方向、距离、强度、时间 |
| 预处理 | 去畸变、金字塔、曝光处理 | 去畸变、滤波、下采样 |
| 数据关联 | 描述子、光流、投影搜索 | 最近点、点到面、分布匹配 |
| 位姿残差 | 重投影/光度误差 | 点到点/线/面/NDT 误差 |
| 短时预测 | 恒速、IMU | 恒速、IMU、轮速 |
| 局部地图 | 特征点与关键帧 | 点云/体素/子地图 |
| 后端 | BA、视觉惯性图 | 位姿图、激光惯性图 |
| 回环 | 图像检索 + 几何验证 | 扫描检索 + 点云验证 |

传感器不同，估计世界观相同。

## 18. 激光是不是一定比视觉稳

不能脱离场景回答：

- 黑暗环境中激光通常占优；
- 大量几何重复、长隧道或空旷区会让激光退化；
- 相机能提供纹理和语义，激光给直接尺度几何；
- 雨雾、玻璃、强光对不同传感器影响不同；
- 成本、重量、功耗、视场和运动速度也不同。

选择传感器不是给算法排名，而是分析任务中哪些状态方向需要什么独立证据。

## 19. 本章最小结论

1. 激光直接测局部方向和距离，但全局位姿与地图仍需估计。
2. 一帧机械扫描跨越时间，运动中必须用逐点时刻去畸变。
3. ICP 交替建立对应并优化位姿；点到面残差利用表面结构。
4. NDT 用局部点分布描述目标地图，仍依赖参数、初值和几何可观性。
5. 长走廊和单平面会产生弱约束方向，低残差不等于全六自由度都可靠。
6. LIO 用 IMU 高频传播和去畸变，激光配准再修正惯性漂移。
7. 视觉和激光最终都遵循测量、关联、残差、局部地图、后端与回环的统一主线。
