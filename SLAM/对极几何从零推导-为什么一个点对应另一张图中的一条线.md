# 对极几何从零推导：为什么第一张图的一个点，在第二张图中对应一条线

> **主线位置**：读到[05 两帧运动估计](05-两帧运动估计.md)的本质矩阵时，可以转入本文。
>
> **目标**：不从八点法和矩阵分解开始，只从“同一个三维点被两个相机看见”推到 `x_2ᵀ[t]×R x_1=0`，并解释每一步为什么成立。

## 1. 我们到底已经知道什么

两台相机在两个位置观察同一个静态三维点 `P`。

在第一张图中测到像素 `p_1`，在第二张图中测到像素 `p_2`。使用相机内参去掉像素尺度和主点影响，得到两条归一化射线方向：

```text
x_1 = K_1⁻¹ p_1
x_2 = K_2⁻¹ p_2
```

- `K_1、K_2`：两台或两个时刻相机的内参矩阵；
- `p_1、p_2`：像素的齐次坐标 `[u,v,1]ᵀ`；
- `x_1、x_2`：相应的归一化相机射线方向。

我们还不知道点沿每条射线有多远，因此存在深度 `Z_1、Z_2`：

```text
P_1 = Z_1 x_1
P_2 = Z_2 x_2
```

- `P_1`：三维点在第一相机坐标系中的坐标；
- `P_2`：同一个三维点在第二相机坐标系中的坐标。

## 2. 两个相机坐标之间怎样联系

假设第一相机坐标中的三维点经过相对旋转 `R` 和平移 `t`，变到第二相机坐标：

```text
P_2 = R P_1 + t
```

代入射线表达：

```text
Z_2 x_2 = R(Z_1 x_1) + t
```

整理成：

```text
Z_2 x_2 = Z_1 R x_1 + t
```

现在有四类对象：

- `x_1、x_2`：图像测得的射线方向，已知；
- `R、t`：我们想估计的两相机相对运动；
- `Z_1、Z_2`：每个点各自未知的深度。

如果每对匹配都携带两个未知深度，直接求共同运动会很麻烦。对极约束的关键就是：先把 `Z_1、Z_2` 消掉。

## 3. 先不用公式：三条方向为什么一定共面

以第二相机坐标系为参考：

- `t`：从第二相机原点指向第一相机原点的方向，具体正负随变换约定，但它位于两个相机中心连线上；
- `R x_1`：第一相机看到点 P 的射线，旋转到第二相机方向表达；
- `x_2`：第二相机直接看到点 P 的射线。

两个相机中心和点 P 一定决定一个平面，叫对极平面。这三条向量都躺在这个平面中。

```text
第一相机中心 C₁
       \
        \  射线 R x₁
         P
        /
       /  射线 x₂
第二相机中心 C₂

C₁ 与 C₂ 的连线方向由 t 表达
```

真正有用的信息不是每条射线有多长，而是：

> `t、R x_1、x_2` 三个方向必须共面。

这条共面关系不需要知道 `Z_1、Z_2`。

## 4. 怎样用叉积得到这个平面的法向量

两个不平行向量做叉积，结果垂直于它们所在平面。

因此：

```text
n = t × (R x_1)
```

- `n`：由 `t` 和 `R x_1` 张成平面的法向量；
- `×`：三维叉积。

既然 `x_2` 也躺在同一个平面中，它就应与法向量 `n` 垂直。

两个向量垂直，点积等于零：

```text
x_2ᵀ n = 0
```

代入 `n`：

```text
x_2ᵀ (t × R x_1) = 0
```

到这里，两个未知深度已经完全不见了。

## 5. `[t]×` 只是把“与 t 做叉积”写成矩阵

对三维向量：

```text
t = [t_x, t_y, t_z]ᵀ
```

定义反对称矩阵：

```text
       [  0   -t_z   t_y ]
[t]× = [ t_z   0    -t_x ]
       [-t_y  t_x    0   ]
```

它满足：

```text
[t]× a = t × a
```

所以共面关系可以写成矩阵乘法：

```text
x_2ᵀ [t]× R x_1 = 0
```

定义：

```text
E = [t]× R
```

就得到：

```text
x_2ᵀ E x_1 = 0
```

`E` 就是 Essential Matrix（本质矩阵）。

它没有创造新的物理，只是把“两条射线与相机中心连线必须共面”这句话压缩进一个 `3×3` 矩阵。

## 6. 用一个简单向量例子检查“共面点积为零”

假设为了便于想象：

```text
t     = [1, 0, 0]ᵀ
R x_1 = [0, 0, 1]ᵀ
```

它们分别沿 `x` 轴和 `z` 轴，因此张成 `x-z` 平面。

叉积：

```text
n = t × R x_1 = [0, -1, 0]ᵀ
```

法向沿 `y` 轴。

第二条正确射线若也在 `x-z` 平面，可写成：

```text
x_2 = [a, 0, c]ᵀ
```

点积：

```text
x_2ᵀ n
= [a,0,c] [0,-1,0]ᵀ
= 0
```

如果错匹配让 `x_2` 有明显 `y` 分量，点积就不再接近零。这就是对极残差能做几何验证的直觉。

## 7. 为什么第一张图的一个点对应第二张图的一条极线

固定第一帧点 `x_1` 和两相机几何 `E`：

```text
l_2 = E x_1
```

`l_2` 是第二张归一化图像中的一条直线参数。第二帧正确匹配 `x_2` 必须满足：

```text
x_2ᵀ l_2 = 0
```

齐次二维直线可写为：

```text
l_2 = [a,b,c]ᵀ
```

像素点 `x_2=[u,v,1]ᵀ` 在这条线上，等价于：

```text
au + bv + c = 0
```

所以：

```text
第一帧一个像素
→ 空间中一整条射线
→ 这条射线投到第二张图
→ 第二张图中的一条极线
```

未知深度让候选不能缩成第二张图中的一个点，却能从整张二维图缩成一条一维线。

## 8. 从本质矩阵 E 到基础矩阵 F

本质矩阵使用去掉内参后的归一化射线：

```text
x_1 = K_1⁻¹ p_1
x_2 = K_2⁻¹ p_2
```

代入：

```text
(K_2⁻¹ p_2)ᵀ E (K_1⁻¹ p_1) = 0
```

利用转置关系整理：

```text
p_2ᵀ K_2⁻ᵀ E K_1⁻¹ p_1 = 0
```

定义：

```text
F = K_2⁻ᵀ E K_1⁻¹
```

得到像素坐标中的约束：

```text
p_2ᵀ F p_1 = 0
```

- `E`：已知内参并使用归一化射线时的相机相对几何；
- `F`：把内参也包含进去，直接作用在像素坐标上；
- `K⁻ᵀ`：`K⁻¹` 的转置，也等于 `(Kᵀ)⁻¹`。

## 9. 为什么 E 只能给平移方向，不能给长度

若把平移 `t` 放大为 `s t`：

```text
E' = [s t]× R = s [t]× R = sE
```

放进约束：

```text
x_2ᵀ E' x_1
= x_2ᵀ (sE) x_1
= s × 0
= 0
```

任意非零尺度 `s` 都不改变约束是否成立。因此 `E` 可以恢复平移方向，但不能只凭两张单目图确定平移的米制长度。

这不是求解器遗漏了一个步骤，而是图像证据本身对整体尺度不敏感。

## 10. 为什么一对匹配不够估计 E

一个匹配只提供一条标量方程：

```text
x_2ᵀ E x_1 = 0
```

而 `E` 中包含共同的相对旋转和平移方向信息，需要多对、空间分布良好的匹配共同约束。

经典算法会用五对、八对等最小或线性方法产生候选，再在 RANSAC 中反复抽样。算法名称不是本专题重点，重点是：

```text
每对正确匹配提供一个共面约束
许多匹配共同指向同一组相机运动
错误匹配通常不服从这组共同几何
```

## 11. 有噪声时为什么不可能真的等于零

实际像素、内参和位姿都有误差，所以正确匹配也通常满足：

```text
x_2ᵀ E x_1 ≈ 0
```

而不是精确等于零。

要定义“离极线有多远”的误差，并结合像素噪声选择阈值。直接代数值 `x_2ᵀ E x_1` 的尺度会受直线参数影响，工程中常使用点到极线距离或 Sampson 近似等更有意义的几何误差。

第一遍只需记住：`=0` 是理想模型，RANSAC 阈值和后续优化面对的是带噪声现实。

## 12. 从 E 分解出 R、t 为什么要做正深度检查

同一个 `E` 分解后通常产生多组旋转和平移方向候选。几何代数本身还没有告诉你哪个候选让场景位于相机前方。

因此：

```text
E
↓ 分解
若干 R,t 候选
↓ 用每组候选三角化点
检查多少点在两个相机前方、视差和重投影是否合理
↓
选择物理可行候选
```

这再次说明：矩阵分解输出候选，物理与数据验收决定候选能否被系统接受。

## 13. 极线约束能做什么，不能做什么

能做：

- 从两帧正确匹配约束相对旋转和平移方向；
- 检查候选匹配是否符合共同几何；
- 把第二帧对应搜索从整张图缩到极线附近；
- 为三角化建立两相机相对几何。

不能单独做：

- 确定单目米制尺度；
- 在纯旋转或极小视差时可靠恢复深度；
- 自动证明数据关联正确；
- 在动态场景中保证所有点服从同一运动；
- 代替后续重投影优化和系统验收。

## 14. 把整段推导念成一句人话

```text
第一帧像素给一条射线 x₁
→ 相对旋转后方向是 R x₁
→ 两相机中心连线方向是 t
→ 它们决定一个对极平面
→ 第二帧正确射线 x₂ 必须也在平面里
→ 平面法向是 t × R x₁
→ 平面内向量与法向点积为零
→ x₂ᵀ[t]×R x₁ = 0
→ 定义 E=[t]×R
→ x₂ᵀE x₁=0
```

这就是本质矩阵公式的来处。
