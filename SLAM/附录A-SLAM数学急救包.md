# 附录 A：SLAM 数学急救包——卡在哪里，就补到哪里

> 这不是要求从头背完的数学教材。正文遇到符号卡住时，查对应小节；先理解它在描述什么，再决定是否手算。

## A.1 数、向量、矩阵分别是什么

### 标量

一个普通数，例如：

```text
深度 Z = 3 米
时间 Δt = 0.01 秒
```

### 向量

把一组有关联的数按顺序放在一起。例如三维位置：

```text
    [ x ]
p = [ y ]
    [ z ]
```

它是 `3×1` 列向量。向量不只是三个数字，还必须知道：

- 它代表位置、方向、速度还是误差；
- 它在哪个坐标系中；
- 它的单位是什么。

### 矩阵

按行列排列的一组数。矩阵可以：

- 表示线性变换；
- 把多个方程一起写；
- 描述不同变量之间的敏感关系或不确定性。

例如二维旋转 90°：

```text
    [ 0  -1 ]
R = [ 1   0 ]
```

作用在 `[1,0]ᵀ` 上得到 `[0,1]ᵀ`。

## A.2 下标、上标和帽子怎样读

本教程统一：

```text
p_c：点 p 在相机坐标系 c 中的坐标
T_wc：把 c 坐标系中的坐标变到 w 坐标系
x_hat：x 的估计值
x_real：现实中的真实值
z_k：第 k 次测量
Rᵀ：R 的转置
R⁻¹：R 的逆
```

`hat` 不是变量的新类型，只提醒它是算法估计而非真值。

## A.3 矩阵乘法到底在做什么

矩阵 `A` 乘向量 `x`：

```text
y = A x
```

可理解为：`A` 按各行规定的方式组合 `x` 的分量，得到新向量 `y`。

维度必须接得上：

```text
(m×n) 矩阵 × (n×1) 向量 = (m×1) 向量
```

中间的 `n` 相同。

矩阵乘法通常不可交换：

```text
AB ≠ BA
```

坐标变换链从右向左执行：

```text
p_w = T_wb T_bc p_c
c → b → w
```

## A.4 转置是什么

转置把行和列交换：

```text
      [ 1 ]
[1 2]ᵀ = [ 2 ]
```

常见用途：

- 把列向量写成行向量；
- 构造内积 `aᵀb`；
- 在最小二乘中出现 `JᵀJ`；
- 旋转矩阵的逆恰好等于转置：`R⁻¹ = Rᵀ`。

## A.5 逆是什么

若：

```text
y = A x
```

且 `A` 可逆，则：

```text
x = A⁻¹ y
```

`A⁻¹` 撤销 `A` 的作用，就像乘法中的除法。

但并非所有矩阵都可逆。测量对某个方向没有约束时，相关系统可能奇异，无法唯一撤销。

数值计算通常不显式求 `A⁻¹` 再乘，而是直接解线性方程 `Ax=b`，更快、更稳定。

## A.6 点积是什么

两个三维向量：

```text
aᵀb = a_x b_x + a_y b_y + a_z b_z
```

几何上：

```text
aᵀb = ||a|| ||b|| cosθ
```

- `||a||`：向量 `a` 的长度；
- `θ`：两向量夹角。

用途：

- 判断方向相似；
- 把一个向量投影到另一个方向；
- 点到平面残差 `nᵀ(p-q)`。

若两个向量垂直，点积为零。

## A.7 叉积是什么

三维向量叉积：

```text
c = a × b
```

结果 `c` 垂直于 `a、b` 所在平面，方向按右手规则，长度为：

```text
||c|| = ||a|| ||b|| sinθ
```

常用来：

- 求平面法向；
- 表达转动效果；
- 写对极几何中的 `[t]×`。

向量 `t = [t_x,t_y,t_z]ᵀ` 可写成反对称矩阵：

```text
       [  0   -t_z  t_y ]
[t]× = [ t_z   0   -t_x ]
       [-t_y  t_x   0   ]
```

满足：

```text
[t]× a = t × a
```

这个矩阵只是把“与 `t` 做叉积”写成矩阵乘法。

## A.8 范数是什么

向量二范数就是普通长度：

```text
||r|| = sqrt(r_1² + r_2² + ...)
```

平方范数：

```text
||r||² = rᵀr
```

最小二乘经常最小化平方范数，因为不需要每项开方，并且易求导。

## A.9 导数先理解为“变化率”

函数：

```text
y = f(x)
```

导数 `dy/dx` 回答：`x` 轻微增加时，`y` 大约改变多少。

例子：

```text
f(x)=x²
df/dx=2x
```

在 `x=3` 附近，`x` 增加 `0.01`，`f` 约增加：

```text
2×3×0.01 = 0.06
```

导数在优化中告诉我们：改变状态会怎样改变残差。

## A.10 偏导数和雅可比矩阵

若函数依赖多个变量：

```text
r(x,y)
```

只改变 `x`、保持 `y` 不变得到对 `x` 的偏导；反之亦然。

若状态向量有 `n` 个分量，残差向量有 `m` 个分量，雅可比 `J` 是 `m×n` 矩阵：

```text
J_ij = 第 i 个残差对第 j 个状态分量的偏导
```

线性近似：

```text
r(x + Δx) ≈ r(x) + J Δx
```

每列回答一个状态方向怎样影响全部残差；每行回答一个残差受哪些状态影响。

## A.11 一阶泰勒展开与线性化

弯曲函数在某个点附近可以用切线近似：

```text
f(x_0 + Δx) ≈ f(x_0) + f'(x_0) Δx
```

- `x_0`：当前展开点或当前猜测；
- `Δx`：准备尝试的小变化；
- `f'(x_0)`：当前斜率。

离 `x_0` 越远，近似通常越不可靠。因此非线性优化每走一步就重新线性化，而不是用第一条切线走到底。

## A.12 最小二乘的线性方程从哪里来

线性化残差：

```text
r(x+Δx) ≈ r + JΔx
```

希望平方和最小：

```text
min ||r + JΔx||²
```

对 `Δx` 求导并令其为零，可得正规方程：

```text
JᵀJ Δx = -Jᵀr
```

加权时：

```text
JᵀWJ Δx = -JᵀWr
```

常缩写：

```text
H Δx = -g
H = JᵀWJ
g = JᵀWr
```

它在问：根据当前残差和敏感关系，本轮最合适的小更新是多少。

## A.13 平均值、方差和标准差

测量 `z_1...z_N` 的平均值：

```text
μ = (1/N) Σ z_i
```

方差描述测量围绕平均值的分散程度：

```text
σ² = (1/N) Σ (z_i - μ)²
```

标准差：

```text
σ = sqrt(σ²)
```

标准差与原测量单位相同。方差越大，说明测量波动通常越大。

## A.14 高斯分布先看形状

一维高斯分布像钟形：

- 平均值附近最常见；
- 离平均值越远，概率越低；
- 标准差决定钟形有多宽。

SLAM 常把传感器小噪声近似为高斯，因为它能导出方便的加权最小二乘。但错匹配、动态物体和时间错位通常不是普通高斯小噪声，必须单独处理。

## A.15 协方差矩阵是什么

多维误差不仅每个轴大小不同，轴之间还可能相关。协方差矩阵：

```text
    [ σ_x²       cov(x,y) ]
Σ = [ cov(y,x)   σ_y²     ]
```

- 对角线：每个方向的方差；
- 非对角线：两个方向误差是否一起变化。

二维位置不确定性可画成椭圆：长轴方向表示更不确定。

信息矩阵常为：

```text
W = Σ⁻¹
```

协方差大、信息小；协方差小、信息大。

## A.16 概率、似然和后验只抓住三个问题

### 先验 Prior

看到当前测量前，根据历史最相信状态在哪里。

### 似然 Likelihood

如果状态候选是某个值，产生当前测量的可能性多大。

### 后验 Posterior

结合先验和当前测量后，对状态的新判断。

贝叶斯思想：

```text
后验 ∝ 似然 × 先验
```

滤波不断把上一时刻后验传播成下一时刻先验，再用新测量更新。图优化则把许多似然和先验因子放在一起求最可能状态。

## A.17 `argmin` 和 `argmax` 是什么

```text
x_hat = argmin_x cost(x)
```

不是说 `x_hat` 等于最小代价值，而是：

> `x_hat` 是那个能让 `cost(x)` 取得最小值的 `x`。

同理 `argmax` 返回让函数最大的自变量。

## A.18 特征值的最小直觉

矩阵 `H` 对某些特殊方向 `v` 只改变长度、不改变方向：

```text
H v = λ v
```

- `v`：特征向量，代表一个状态组合方向；
- `λ`：对应特征值，代表该方向的强度。

在优化信息矩阵中：

- 大特征值方向通常约束强；
- 很小特征值方向通常约束弱；
- 零特征值可能对应完全不可观或规范自由度。

这帮助理解走廊退化和单目尺度不可观。

## A.19 SVD 的直觉

SVD（Singular Value Decomposition，奇异值分解）把矩阵分解成：

```text
A = U Σ Vᵀ
```

可以直观理解为：

```text
先换一个输入方向坐标 → 按不同方向缩放 → 再旋转到输出方向
```

奇异值描述各方向被放大或压缩多少。接近零的奇异值表示某些输入方向几乎无法从输出区分。

SVD 用于：

- 求最小二乘和秩；
- 2D–2D 几何中的矩阵分解；
- 3D–3D 对齐；
- 检查退化。

## A.20 旋转矩阵为什么有约束

合法三维旋转矩阵满足：

```text
RᵀR = I
det(R) = 1
```

- `I`：单位矩阵；
- `det(R)`：行列式；
- 第一条保证三根轴互相垂直且长度不变；
- 第二条排除镜像反射。

旋转矩阵有 9 个数字，却只有 3 个独立自由度。不能把 9 个数当普通变量随意修改。

## A.21 四元数为什么有四个数却只有三自由度

单位四元数常写：

```text
q = [w, x, y, z]
```

满足：

```text
w²+x²+y²+z² = 1
```

单位长度约束去掉一个自由度，所以仍为 3 自由度。并且 `q` 与 `-q` 表示同一个旋转。

不同库的分量顺序可能不同，接口处必须确认。

## A.22 `SO(3)`、`SE(3)`、李代数为何出现

- `SO(3)`：所有合法三维旋转矩阵的集合；
- `SE(3)`：所有三维刚体位姿的集合；
- 李代数：在某个旋转或位姿附近，用普通小向量表达微小变化的局部空间。

优化器喜欢普通向量增量，但旋转必须保持合法。于是：

```text
普通小向量 δθ
      ↓ Exp 指数映射
合法小旋转 Exp(δθ)
      ↓ 与当前旋转相乘
更新后的合法旋转
```

第一遍只要理解它是“合法地给旋转加一个小修正”的工具。

## A.23 左乘更新与右乘更新为什么会改变雅可比

位姿更新可以写成：

```text
左乘：T_new = Exp(δξ) T_old
右乘：T_new = T_old Exp(δξ)
```

- `δξ`：6 维小位姿增量，含小平移与小旋转；
- `Exp(...)`：把它变成合法刚体小变换。

左乘增量和右乘增量分别在不同坐标表达下作用，导数形式会不同。阅读代码时必须确认扰动模型，不能把某教材的雅可比直接抄到另一约定。

## A.24 齐次坐标中的 `∼` 是什么

```text
p' ∼ H p
```

表示两边只要求相差一个非零比例，因为齐次坐标：

```text
[u, v, 1]ᵀ
```

与：

```text
[su, sv, s]ᵀ
```

在除以最后一维后代表同一个普通点。

## A.25 数值稳定性最小清单

- 解 `Ax=b`，通常不要显式求逆；
- 注意米、毫米、像素、弧度、度等单位尺度；
- 检查 NaN、无穷大、负深度和除以接近零；
- 对旋转矩阵和四元数维持合法约束；
- 看矩阵条件数或最小特征值判断病态；
- 用解析导数、自动微分或有限差分互相验证雅可比；
- 先用小合成例子验证坐标方向，再跑大数据集；
- 求解器“成功”后仍检查物理与统计结果。

## A.26 看公式时固定问五句话

1. 左边是什么量，单位和坐标系是什么？
2. 右边每个符号从传感器、标定、当前估计还是固定模型而来？
3. 这是现实物理关系、预测测量，还是优化更新？
4. 哪些量已知，哪些量是待估变量？
5. 在什么情况下这个关系不再成立或约束变弱？

能回答这五句，通常已经真正理解了公式在系统中的位置。
