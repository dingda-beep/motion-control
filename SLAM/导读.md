# SLAM 导读：先理解迷雾中的机器人，再学算法

这不是一套要求你先学完线性代数、概率论、三维几何和优化，才有资格开始的教程。

我们先把一台机器人放在没有先验地图、GPS 也不可用的楼里。它每次只能看到一小块局部世界，而且所有传感器都会带着噪声、延迟和盲区。

从这个场景出发，所有 SLAM 概念都有自己出现的理由：

```text
只看见局部 → 需要坐标系把不同时刻的证据放到一起
图像没有直接深度 → 需要多视图几何或额外深度传感器
同一个地点在不同帧长得不一样 → 需要数据关联
匹配带噪声 → 需要用多个证据联合估计
每次只估一点相对运动 → 长时间累积必然漂移
又回到旧地方 → 新的长程约束可以纠正过去的轨迹
算法不能无限保留所有图像 → 需要关键帧、滑动窗口和边缘化
```

## 1. 先建立一个不可动摇的世界观

SLAM 系统永远面对三类对象：

```text
现实：机器人真正在哪里，世界真正长什么样
证据：传感器这一次实际测到了什么
估计：算法根据当前和历史证据，现在最相信什么
```

用符号写成：

```text
x_real   真实轨迹或真实位姿
m_real   真实环境
z        传感器测量
x_hat    算法估计的轨迹或位姿
m_hat    算法估计的地图
```

SLAM 程序能直接拿到的是 `z`，不是 `x_real`和 `m_real`。`x_hat`和 `m_hat` 是根据证据推断出来的当前答案，仍可能会错。

以后看到“这一帧的位姿”、“地图点”或“回环约束”时，都要问：

> 这是现实真值、传感器原始测量，还是算法当前的估计？

## 2. 三遍阅读法

### 第一遍：只追因果链

不要停下来手算矩阵，只要能用自己的话回答：

```text
当前方法拿到什么证据？
它想估计什么？
它为什么不能只用一次测量？
它会在什么条件下失败？
它的输出交给了谁？
```

### 第二遍：再看最小数学

重点理解：

- 坐标变换的方向；
- 投影和重投影误差；
- 为什么要对残差平方求和；
- 线性化是怎样在当前猜测附近做小步修正；
- 不确定性怎样沿时间积累；
- 什么叫不可观，为什么算法再强也不能凭空恢复缺失信息。

### 第三遍：放回真实系统

这时才重点看：

- 时间戳和多线程队列；
- 相机、IMU、激光和机体外参；
- 传感器曝光、滚动快门、点云扫描时间；
- 初始化、跟踪丢失、重定位和地图保存；
- 真值怎样对齐，轨迹指标到底评价了什么；
- 输出的地图是给人看，还是给规划器和控制器使用。

## 3. 数学应该怎样按需补

| 读到哪里卡住 | 先补什么 | 不需要先学完什么 |
|---|---|---|
| 坐标变换方向 | 向量、矩阵乘法、旋转与平移 | 不需要先背 SE(3) 指数映射 |
| 相机投影 | 相似三角形、坐标除以深度 | 不需要先学完射影几何 |
| 对极几何 | 一条光线不能决定深度、两个观测位置产生视差 | 不需要第一遍手推八点法 |
| 优化 | 误差、平方、导数和当前猜测附近的直线近似 | 不需要先学完数值优化教材 |
| IMU 融合 | 速度、加速度、积分、偏置与噪声 | 不需要先手推全部预积分雅可比 |
| 因子图 | 变量、测量约束和残差 | 不需要先掌握稀疏 Cholesky 实现 |

遇到具体符号时，查[SLAM 数学急救包](附录A-SLAM数学急救包.md)；遇到缩写时，查[缩写与符号速查](附录B-SLAM缩写与符号速查.md)。

## 4. 每章必须回答的八个问题

1. 这一章的现实困难是什么？
2. 输入是真实世界、传感器测量，还是上一步估计？
3. 未知量是相机位姿、地图点、速度、偏置，还是数据关联？
4. 这些未知量为什么能由当前证据约束？
5. 公式里的每个符号是谁，从哪里来？
6. 方法输出的是候选、局部最优还是已验证的结果？
7. 什么运动、场景、噪声或错匹配会让它失败？
8. 它的输出交给下一章的谁？

如果正文无法回答这些问题，应该把它视为讲义本身的断点，不是读者“基础太差”。

## 5. 学完以后真正应该会什么

不是默写 ORB、PnP、BA 的定义，而是面对一个 SLAM 系统时能够问对问题：

```text
现在漂移是因为测量证据不足，还是匹配错了？
系统没跟上，是运动太快、图像太暗，还是时间戳错了？
位姿突跳，是回环真正纠正了轨迹，还是假回环把地图拉坏了？
地图看起来很密，它真的能给避障和规划使用吗？
更换相机或增加 IMU 后，哪些标定、模型和时间契约必须一起变？
```

能够沿着“现实→测量→关联→估计→优化→地图→下游任务”的因果链定位问题，才是这套教程的最终目标。
