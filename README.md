# 机器人运动控制与 SLAM 教程

这个仓库按“一个大问题，一套连续主线”组织为三个专题：

| 专题 | 核心问题 | 入口 |
|---|---|---|
| 运动控制 | 机器人怎样根据目标、估计状态和现实反馈，持续产生可执行动作 | [运控教程](运控/README.md) |
| RL 训练与部署 | 怎样从任务定义、仿真训练和奖励调试，一步步得到有资格进入真机测试的运控策略 | [RL 训练与部署实战](RL训练与部署/README.md) |
| SLAM | 机器人没有上帝视角的坐标和地图时，怎样利用连续、带噪声、可能匹配错误的传感器证据，一边判断自己在哪里，一边建立可继续使用的世界 | [SLAM 教程](SLAM/README.md) |

三套讲义的共同原则是：

```text
先给出现实问题
→ 再引出必要概念
→ 公式紧跟物理含义和符号解释
→ 复杂推导允许第二遍再读
→ 最后回到真实系统的接口、边界和失败因果
```

它们不是缩写辞典。如果一个名词无法在整条因果链中回答“为什么现在需要它”，就不应只把它作为孤立定义塞给读者。
