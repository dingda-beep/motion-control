# 12 鲁棒化与特权学习

## 12.0 随机化改变的是训练环境的输入参数

```text
# 先按有证据的范围，采样“这一回合的世界是什么样”。
world_parameters = sample(
    randomization_ranges, # 质量、摩擦、延迟等参数的范围与分布
    seed                  # 记录种子后才能复现同一个随机世界
)

# 再让同一个 Actor 在这个世界中生活一段时间并收集经验。
rollout = simulate(
    actor,          # 只接收其被允许看到的观测
    world_parameters # 通常不直接告诉 Actor，而是影响身体的实际响应
)
```

输入的 `randomization_ranges` 应来自实测和工程依据；输出是不同质量、摩擦、延迟等条件下的经验。actor 并不一定直接收到这些参数，它常要从身体响应和历史中适应它们。

## 12.1 Sim2Real 的问题不是“仿真不够真”这一句话

更准确地说，训练策略适应的是某个仿真分布：

\[
p_{sim}(x_{t+1},y_t\mid x_t,a_t,\theta)
\]

真机的质量、摩擦、延迟、噪声和执行器响应并不与某个固定 \(\theta\) 完全相同。鲁棒化要做的是：让训练覆盖一组可能世界，并让策略仍能从可用观测中采取有效动作。

## 12.2 Domain Randomization 在随机什么

常见项包括：

| 类别 | 例子 | 主要模拟什么差异 |
|---|---|---|
| 刚体 | 质量、质心、惯量 | 模型和载荷不准 |
| 接触 | 摩擦、恢复、地形 | 鞋底与地面变化 |
| 执行器 | Kp/Kd、力矩系数、摩擦、延迟 | 电机与传动差异 |
| 传感器 | 噪声、偏置、量化、丢帧 | 真机测量不完美 |
| 通信 | 观测/动作延迟、周期抖动 | 软件与总线时序 |
| 外界 | 推力、载荷、轻微碰撞 | 扰动恢复 |

当前参考任务已经随机化地面摩擦、躯干附加质量，并周期性给基座水平速度扰动。这只是起点，不代表覆盖了真机全部差异。

## 12.3 随机范围从证据来，不从勇气来

范围过窄，真机落在分布外；范围过宽，策略为了适应互相矛盾的世界而过度保守，甚至学不会。

更可靠的来源：

1. 厂家数据和机械公差；
2. 台架与真机日志辨识；
3. 不同地面和载荷实测；
4. 控制周期与网络延迟统计；
5. Sim2Sim 与真机残差；
6. 故障案例暴露出的遗漏。

随机化不是把所有参数乘 `[0.5, 1.5]`。每个范围都应带单位、分布、相关性和依据。

## 12.4 随机化与扰动不是一回事

- 参数随机化改变“这个世界是什么样”；
- 外力或速度推扰改变“这个世界刚刚发生了什么”。

质量变重后整个回合都可能持续，推一下则是瞬时事件。两者训练出的能力不同：前者偏向模型鲁棒性，后者偏向状态恢复。

## 12.5 特权学习用在哪个阶段

在本案例的 PPO 训练阶段：

```text
actor：只看真机可构造的观测               # 最终导出并在真机每周期执行
critic：可额外看仿真真值，例如基座线速度  # 只在训练期辅助评价，不随 Actor 部署
```

critic 利用更完整信息估计价值，给 actor 更低噪声的学习信号；actor 自始至终没有依赖部署不可用信息。因此导出时拿走 critic，actor 仍能独立运行。

特权学习的核心不是“用了真值就更强”，而是：

> 训练阶段用部署不可得的信息改善监督或价值估计，但最终执行路径必须只依赖部署可得输入。

还有一种教师—学生路线：教师在仿真中看特权信息学会能力，再通过蒸馏让学生仅凭历史和传感器观测模仿教师。此时特权信息参与教师或辅助目标，最终学生仍不能需要它。

## 12.6 历史为何能帮助适应隐变量

质量和摩擦未必直接放进 actor 输入，但最近几帧包含：

```text
我发了什么动作
→ 关节和身体怎样响应
```

同样动作下，重身体、低摩擦或大延迟会呈现不同响应。历史让网络有机会从输入—响应关系中隐式推断这些未观测条件。

这不是保证网络一定完成系统辨识，但解释了为什么 `last_action + 状态历史` 常对鲁棒控制有帮助。

## 12.7 鲁棒性也会被“平均”掩盖

评估时把随机参数分箱：

```text
摩擦：低 / 中 / 高
附加质量：轻 / 中 / 重
延迟：0 / 10 / 20 / 30 ms
扰动：方向 × 大小
```

报告每个格子的成功率与极值。平均 95% 可能意味着所有格子都接近 95%，也可能意味着常见条件 100%、低摩擦全部失败。部署包络由后者决定。

## 12.8 系统辨识仍然重要

RL 加随机化不等于不用了解动力学。相反，只有知道哪些参数显著影响未来，才能选择随机化对象和合理范围；只有理解动作—运动因果，才能从 Sim2Sim/真机失败中判断是摩擦、延迟、增益、惯量还是观测问题。

动力学模型帮助你定义“可能的未来集合”，RL 在这个集合里学习行为。两者不是替代关系。
