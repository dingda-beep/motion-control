# 附录 C：训练与部署词语表

这不是要求背诵的单词表。阅读某章被一个词卡住时来查，知道它在整条闭环中负责什么就够了。

## 学习算法

| 词 | 中文和最短解释 |
|---|---|
| RL | Reinforcement Learning，强化学习。策略通过行动得到奖励，用长期结果反过来改变行为。 |
| policy / strategy | 策略。输入当前观测，输出动作的规则；本教程里主要指 actor 神经网络。 |
| actor | 行动者。根据可部署观测产生 29 维动作，最终会被导出。 |
| critic | 评价者。训练时估计当前局面未来能得多少回报，帮助 actor 学习，部署时通常不用。 |
| MLP | Multi-Layer Perceptron，多层感知机。数据依次通过多层线性变换和非线性函数的网络；actor 和 critic 都可以是 MLP。 |
| PPO | Proximal Policy Optimization，近端策略优化。利用新采样的数据更新策略，并限制一次更新过猛。 |
| on-policy | 同策略数据。主要使用当前或非常接近当前的策略刚采到的数据学习，策略更新后再收集新数据。 |
| rollout | 策略在环境中运行一小段得到的记录，包含观测、动作、奖励、终止和价值估计。 |
| transition | 一条状态转移记录，可粗看成“看见什么、做了什么、得到什么、来到哪里”。 |
| iteration | 训练迭代。通常包含一次批量 rollout 和随后若干次参数更新，不等于一个仿真步。 |
| epoch | 对当前训练数据完整学习一遍。PPO 可在同批 rollout 上做若干 epoch。 |
| mini-batch | 从本轮大批样本中切出的一小批，用于一次梯度更新。 |
| checkpoint | 训练过程中的参数快照。后一个通常从前一个继续，不代表每次都从零训练。 |
| return | 回报。从当前时刻开始，未来奖励经过折扣后的累计结果。 |
| advantage | 优势。某个动作的结果相对 critic 原先预期好多少或坏多少。 |
| GAE | Generalized Advantage Estimation，广义优势估计。把多个未来时刻的信息组合起来估计优势。 |
| entropy | 熵。在这里描述策略动作分布有多分散；过早变小常表示探索迅速消失。 |
| KL | Kullback–Leibler divergence，KL 散度。衡量新旧策略分布变化大小的一种量。 |
| seed | 随机种子。固定随机数序列的起点；多种子实验用于排除一次训练的偶然幸运。 |

## 机器人与仿真

| 词 | 中文和最短解释 |
|---|---|
| DoF | Degree of Freedom，自由度。本案例的 29 DoF 指策略控制 29 个关节变量。 |
| URDF | Unified Robot Description Format，常见机器人描述格式，记录连杆、关节、几何和惯性等。 |
| USD | Universal Scene Description，Isaac Sim 常用的场景/资产描述体系。 |
| PD | Proportional–Derivative，比例—微分控制。根据位置误差和速度产生恢复力矩。 |
| decimation | 降采样倍数/动作保持子步数。本案例每个策略动作跨 4 个 5 ms 物理步。 |
| domain randomization | 域随机化。训练时随机改变质量、摩擦、延迟等，让策略适应一组可能世界。 |
| privileged information | 特权信息。训练时可用、部署时不可直接得到的信息，例如仿真真值速度。 |
| Sim2Sim | Simulation to Simulation。同一冻结策略换到另一个仿真实现复核。 |
| Sim2Real | Simulation to Reality，从仿真到现实。关注策略在现实闭环中是否仍成立。 |

## 软件与部署

| 词 | 中文和最短解释 |
|---|---|
| API | Application Programming Interface，应用程序接口。软件之间约定怎样调用和交换数据。 |
| SDK | Software Development Kit，软件开发工具包。厂家提供的通信、状态和控制接口集合。 |
| ONNX | Open Neural Network Exchange，一种交换神经网络计算图和参数的格式。它只是模型，不自动携带全部机器人控制语义。 |
| ONNX Runtime | 执行 ONNX 模型的推理引擎。 |
| normalizer | 归一化器。用训练期统计量变换网络输入；若训练用了，导出或部署不能漏。 |
| schema | 数据结构规范。规定配置必须有哪些字段、类型和关系。 |
| policy contract | 策略契约。规定输入输出每一维的顺序、单位、缩放、历史、周期、关节映射和边界。 |
| golden vector | 黄金测试向量。保存一组固定输入和正确输出，供不同语言/运行时逐项比对。 |
| hash / SHA256 | 文件内容指纹。内容变一点，指纹就变，用于识别拿错或损坏的模型和配置。 |
| deadline | 截止时间。控制周期必须在何时完成；平均很快不代表从不超时。 |
| watchdog | 看门狗。独立检查状态是否更新、线程是否按时运行，异常时触发退出。 |
| fail closed | 失败时关闭许可。遇到未知、缺失或非法数据时拒绝发动作，而不是猜一个值继续。 |
| provenance | 来源记录。说明模型由哪版代码、配置、数据、资源和 checkpoint 产生。 |
| P95 / P99 | 第 95/99 百分位。分别表示约 95%/99% 样本不超过该值，比只看平均值更能暴露尾部风险。 |

## 三组最容易混淆的词

### 模型、策略、发布包

- 神经网络模型：一张数值映射；
- 策略：模型加上输入输出的确切解释；
- 发布包：策略、契约、版本、评估和安全证据的集合。

### 奖励、指标、约束

- 奖励：训练每步用来引导学习的数；
- 指标：人用来判断能力的测量；
- 约束/保护：不允许越过的边界，不能只靠负奖励保证。

### 仿真步、策略步、训练迭代

- 仿真步：物理引擎向前积分一次，本案例 5 ms；
- 策略步：重新计算一次动作，本案例 20 ms；
- 训练迭代：4096 个环境各收集 24 个策略步，再执行一轮 PPO 更新。
