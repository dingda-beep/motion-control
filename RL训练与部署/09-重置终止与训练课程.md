# 09 重置、终止与训练课程

## 9.0 环境还向训练器提供两个接口

```text
done, reason = termination_fn(state, contacts, elapsed_time)
initial_state = reset_fn(random_seed, curriculum_level)
```

终止函数输出“这段经验是否结束以及为什么”；重置函数输出下一回合从哪里开始。它们不进入最终 actor，却决定 actor 在训练中经常见到哪些状态、哪些未来被当成失败。

## 9.1 回合是一段被人为切开的生活

训练会同时运行许多环境。某个机器人摔倒或达到最长时间后，该环境被重置，开始新回合。

当前参考任务的最长回合是 20 秒。策略周期为 0.02 秒，因此一个完整回合最多有：

\[
20/0.02=1000\text{ 个策略步}
\]

回合不是物理世界必须存在的概念，而是为了收集多样经验、控制初始分布和处理失败而建立的训练结构。

## 9.2 初始状态决定策略从哪里学会恢复

如果每次都从完全相同、静止、完美直立的姿态开始，策略可能只会沿一条很窄的轨迹运行。实际部署中的小姿态误差和关节速度就可能把它带出熟悉区域。

重置时可在合理范围随机化：

- 世界位置与朝向；
- 关节位置和速度；
- 基座速度；
- 地形位置；
- 命令；
- 模型和接触参数。

随机范围太小，策略脆弱；太大，初期样本全是无解状态。课程学习可以逐渐扩大。

## 9.3 “摔倒”需要可计算定义

参考任务采用两类终止：

- 基座高度低于 `0.2 m`；
- 身体倾斜超过 `0.8 rad` 的姿态判据。

另外 20 秒超时也结束回合，但超时通常表示正常截断，不等同于摔倒。训练算法在计算价值目标时可能需要区分：

```text
真正终止：进入失败或自然终态
时间截断：只是观察窗口到头，未来本来还能继续
```

混淆两者会改变 critic 对回合末尾未来回报的估计。

## 9.4 终止条件会塑造行为

姿态阈值过紧，机器人刚出现可恢复倾斜就被重置，学不到恢复；阈值过松，大量时间浪费在已经无法站起的地面挣扎中。

因此终止阈值应回答：

1. 这个状态在任务定义中是否已算失败？
2. 策略是否还有现实恢复可能？
3. 继续仿真能否提供有效学习信号？
4. 真机保护阈值是否更保守，为什么？

训练终止阈值和真机安全阈值不必相同。训练可能允许更大偏差以学习恢复，真机则要受硬件和场地安全约束。

## 9.5 扰动不是越狠越好

参考任务可每 5 秒给基座一个随机水平速度扰动，摩擦可在 `[0.3, 1.0]` 采样，躯干质量还会变化。这些变化让策略经历不确定性。

但如果初期就频繁施加强扰动，策略连基础步态都难建立。合理顺序通常是：

```text
基本站立/跟踪
→ 小范围状态随机化
→ 命令范围扩大
→ 质量、摩擦等模型随机化
→ 轻扰动恢复
→ 更困难地形和延迟
```

课程并非固定模板，应由成功率和失败类型驱动。

## 9.6 重置分布也要接近部署入口

真机通常不会从仿真“空中随机姿态”直接进入行走策略，而是经过：

```text
被动状态 → 电机准备 → 插值到默认站姿 → 稳定检查 → 策略接管
```

训练需要覆盖策略接管附近的状态误差；部署状态机也要把机器人带进策略熟悉的入口分布。让策略负责从完全任意姿态起立是另一个任务，不能默认包含在行走任务里。

## 9.7 本章检查

某个模型平均回报更高，但回合长度更短，可能是什么情况？

可能是它在短时间获得较高任务奖励后更常摔倒；也可能是回报按回合求和、超时与终止统计方式造成误读。必须同时查看终止原因分布、每秒回报、回合长度和成功率，不能只凭一个总数判断。
