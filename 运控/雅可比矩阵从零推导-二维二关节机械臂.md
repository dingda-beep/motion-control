# 雅可比矩阵从零推导：只看二维二关节机械臂

> **适合谁**：第一次接触雅可比，看到偏导数和矩阵容易紧张的读者。
>
> **这篇只解决两件事**：
>
> 1. 二维二关节机械臂的雅可比矩阵到底是怎样一步步得到的？
> 2. 为什么雅可比的转置可以把末端力变成关节力矩？

本文不要求你提前学过机器人学。只要知道直角三角形中 `sin`、`cos` 的基本含义即可。遇到导数也不用害怕，我们会先说它在问什么，再进行计算。

---

## 1. 先认识我们研究的机械臂

想象一条只能在纸面上运动的机械臂：

```text
              y
              ↑
                 末端 E(x, y)
                      ●
                     /
                    /  第二段，长度 l₂
                   /
          关节 2  ●
                 /
                /  第一段，长度 l₁
               /
固定底座 O  ●────────────────→ x
```

为了和通常的数学坐标系一致，我们规定：

- 水平向右是 `x` 正方向；
- 竖直向上是 `y` 正方向；
- 逆时针转动为角度正方向；
- 第一段长度是 `l₁`；
- 第二段长度是 `l₂`；
- 第一关节角是 `q₁`；
- 第二关节角是 `q₂`。

这里最容易混淆的是两个角度的定义：

- `q₁` 是第一段相对世界水平线的角度；
- `q₂` 是第二段相对第一段又转过的角度。

所以第二段相对世界水平线的真正角度不是 `q₂`，而是：

```text
q₁ + q₂
```

例如：第一段逆时针转了 `30°`，第二关节又相对第一段逆时针转了 `20°`，那么第二段相对世界水平线就是 `50°`。

后面的全部推导，都建立在这个角度约定上。

---

## 2. 第一步：先算末端在哪里

雅可比并不是凭空出现的。我们必须先知道：

> 给定两个关节角 `q₁`、`q₂`，机械臂末端的坐标 `(x,y)` 是多少？

### 2.1 一根斜杆在 x、y 方向各有多长

一根长度为 `l`、与水平线夹角为 `q` 的杆，可以分解成：

```text
x 方向长度 = l cos(q)
y 方向长度 = l sin(q)
```

可以把它想成这根斜杆在水平墙和竖直墙上分别投下的影子。

因此，第一段连杆贡献的水平和竖直距离是：

```text
x₁ = l₁ cos(q₁)
y₁ = l₁ sin(q₁)
```

第二段相对世界的角度是 `q₁+q₂`，所以它贡献的是：

```text
x₂ = l₂ cos(q₁+q₂)
y₂ = l₂ sin(q₁+q₂)
```

### 2.2 两段相加就是末端坐标

从底座走完第一段，再走完第二段，就到达末端。因此：

```text
x = x₁ + x₂
y = y₁ + y₂
```

代入刚才的结果：

```text
x = l₁ cos(q₁) + l₂ cos(q₁+q₂)
```

```text
y = l₁ sin(q₁) + l₂ sin(q₁+q₂)
```

这两个式子叫做这条机械臂的**正运动学**。名字可以先不记，它做的事情很朴素：把关节角换算成末端位置。

### 2.3 用一个姿势检查公式

假设：

```text
l₁ = 1 m
l₂ = 1 m
q₁ = 0°
q₂ = 90°
```

第一段水平向右，第二段竖直向上。肉眼就能看出末端应该在 `(1,1)`。

代入公式：

```text
x = 1×cos(0°) + 1×cos(90°) = 1
y = 1×sin(0°) + 1×sin(90°) = 1
```

结果确实是：

```text
(x,y) = (1,1)
```

到这里还没有雅可比，我们只是把几何关系写清楚了。

---

## 3. 雅可比究竟想问什么

已知关节角，可以通过上面的公式算出末端位置。但机器人运动时还会问：

> 第一、第二关节正在转动，那么末端此刻会向哪个方向运动？运动多快？

注意这里问的是“此刻”。

关节转过一个大角度以后，机械臂形状会明显改变，末端走的是曲线。雅可比并不试图用一个不变的矩阵描述整段大运动。它只观察当前姿势附近一个非常短的瞬间。

可以把雅可比理解成一张**当前姿势下的运动兑换表**：

```text
关节 1 转动一点，会换来多少 x、y 方向运动？
关节 2 转动一点，会换来多少 x、y 方向运动？
```

机械臂姿势一变，这张兑换表通常也会跟着变。

---

## 4. 偏导数没有那么神秘

末端的 `x` 同时受 `q₁`、`q₂` 影响，`y` 也同时受它们影响。

我们想把影响逐项拆开：

```text
只轻微改变 q₁，x 会变化多少？
只轻微改变 q₂，x 会变化多少？
只轻微改变 q₁，y 会变化多少？
只轻微改变 q₂，y 会变化多少？
```

“只改变其中一个，暂时把其他量看成不变，然后观察结果变化有多快”，就是偏导数在做的事。

写成符号：

```text
∂x/∂q₁：q₁ 轻微变化时，x 对它有多敏感
∂x/∂q₂：q₂ 轻微变化时，x 对它有多敏感
∂y/∂q₁：q₁ 轻微变化时，y 对它有多敏感
∂y/∂q₂：q₂ 轻微变化时，y 对它有多敏感
```

符号 `∂` 读作“偏导”。不要被它吓住，它只是提醒我们：这个结果同时受多个变量影响，现在一次只检查一个。

把这四个敏感程度排成一张表，就是雅可比：

```text
        q₁ 对结果的影响    q₂ 对结果的影响
      ┌                                      ┐
x 行  │      ∂x/∂q₁              ∂x/∂q₂      │
y 行  │      ∂y/∂q₁              ∂y/∂q₂      │
      └                                      ┘
```

也就是：

```text
J(q) =
[
  ∂x/∂q₁   ∂x/∂q₂
  ∂y/∂q₁   ∂y/∂q₂
]
```

为什么这样排？因为我们希望：

- 第一行最后算出末端的 `x` 方向速度；
- 第二行最后算出末端的 `y` 方向速度；
- 第一列表示关节 1 的作用；
- 第二列表示关节 2 的作用。

---

## 5. 正式推导雅可比

我们只需要记住四条简单的求导规则：

```text
cos(q) 对 q 求导，得到 -sin(q)
sin(q) 对 q 求导，得到  cos(q)
常数对 q 求导，得到 0
常数乘在前面，求导后它仍然乘在前面
```

还有一条用于 `q₁+q₂`：

```text
对 q₁ 求导时，把 q₂ 暂时当成常数；
对 q₂ 求导时，把 q₁ 暂时当成常数。
```

### 5.1 先计算 x 对两个关节角的敏感程度

末端的水平坐标是：

```text
x = l₁ cos(q₁) + l₂ cos(q₁+q₂)
```

对 `q₁` 求偏导。两项都包含 `q₁`，所以两项都会变化：

```text
∂x/∂q₁
= -l₁ sin(q₁) - l₂ sin(q₁+q₂)
```

再对 `q₂` 求偏导。第一项 `l₁cos(q₁)` 中没有 `q₂`，所以它对 `q₂` 的导数是 `0`；只有第二项会变化：

```text
∂x/∂q₂
= -l₂ sin(q₁+q₂)
```

### 5.2 再计算 y 对两个关节角的敏感程度

末端的竖直坐标是：

```text
y = l₁ sin(q₁) + l₂ sin(q₁+q₂)
```

对 `q₁` 求偏导：

```text
∂y/∂q₁
= l₁ cos(q₁) + l₂ cos(q₁+q₂)
```

对 `q₂` 求偏导：

```text
∂y/∂q₂
= l₂ cos(q₁+q₂)
```

### 5.3 把四个结果放回表格

于是得到：

```text
J(q) =
[
  -l₁sin(q₁)-l₂sin(q₁+q₂)    -l₂sin(q₁+q₂)
   l₁cos(q₁)+l₂cos(q₁+q₂)     l₂cos(q₁+q₂)
]
```

这就是二维二关节机械臂的位置雅可比。

它看起来长，但来源只有一句话：

> 把末端坐标 `(x,y)` 分别对关节角 `(q₁,q₂)` 求偏导，再按照“输出占行、输入占列”排成表。

你不必背这个最终矩阵。只要能从 `x(q₁,q₂)`、`y(q₁,q₂)` 重新算出来，就真正掌握了它。

## 6. 为什么雅可比乘关节速度就是末端速度

定义：

```text
q̇₁：第一关节每秒转动多少
q̇₂：第二关节每秒转动多少
ẋ：末端每秒在 x 方向移动多少
ẏ：末端每秒在 y 方向移动多少
```

上面的点表示“对时间的变化速度”。例如 `q̇₁` 读作“q 一点”，就是第一关节角速度。

在一个非常短的时间里，末端 `x` 的变化来自两部分：

```text
x 的速度
= q₁ 的速度 × x 对 q₁ 的敏感程度
 + q₂ 的速度 × x 对 q₂ 的敏感程度
```

写成公式：

```text
ẋ = (∂x/∂q₁)q̇₁ + (∂x/∂q₂)q̇₂
```

同理：

```text
ẏ = (∂y/∂q₁)q̇₁ + (∂y/∂q₂)q̇₂
```

把两行合在一起，正好就是矩阵乘法：

```text
[
  ẋ
  ẏ
]
=
J(q)
[
  q̇₁
  q̇₂
]
```

通常简写为：

```text
ṗ = J(q)q̇
```

这里 `p=[x,y]ᵀ` 表示末端位置，`ṗ=[ẋ,ẏ]ᵀ` 表示末端速度。

所以雅可比首先是一台**速度翻译器**：

```text
关节速度 ──J──> 末端速度
```

---

## 7. 按列看雅可比，马上就直观了

把雅可比的两列分别叫作 `J₁`、`J₂`：

```text
J = [ J₁  J₂ ]
```

那么：

```text
ṗ = J₁q̇₁ + J₂q̇₂
```

这句话的含义是：

- `J₁`：只让关节 1 以单位速度转动时，末端速度是多少；
- `J₂`：只让关节 2 以单位速度转动时，末端速度是多少；
- 两个关节同时转时，把它们各自产生的末端速度相加。

### 7.1 为什么每一列都垂直于“关节到末端”的连线

让某一个旋转关节轻微转动时，末端会绕着这个关节画圆。

圆周上一点的瞬时运动方向，一定沿圆的切线；切线又一定垂直于“圆心到这一点”的半径。

所以：

- 雅可比第一列，指向末端绕关节 1 转动时的切线方向；
- 雅可比第二列，指向末端绕关节 2 转动时的切线方向。

如果末端相对某关节的位置向量是：

```text
r = [rₓ, rᵧ]ᵀ
```

把它逆时针旋转 `90°`，就得到切线方向：

```text
[-rᵧ, rₓ]ᵀ
```

对关节 1 来说，末端相对它的位置就是 `[x,y]ᵀ`，因此雅可比第一列是：

```text
J₁ = [-y, x]ᵀ
```

把前面的 `x`、`y` 公式代进去，正好得到：

```text
J₁ =
[
  -l₁sin(q₁)-l₂sin(q₁+q₂)
   l₁cos(q₁)+l₂cos(q₁+q₂)
]
```

这与偏导推导完全一致。

这给了我们第二种理解雅可比的方法：

> 每个旋转关节对应的雅可比列，就是末端绕该关节转动时的瞬时切线速度方向和大小。

偏导是计算方法，绕圆运动是物理直觉，它们说的是同一件事。

---

## 8. 用具体数字完整算一次速度

仍然取：

```text
l₁ = 1 m
l₂ = 1 m
q₁ = 0°
q₂ = 90°
```

此时：

```text
sin(0°)=0
cos(0°)=1
sin(90°)=1
cos(90°)=0
```

把它们代入雅可比：

```text
J =
[
  -1  -1
   1   0
]
```

假设关节速度是：

```text
q̇₁ = 0.2 rad/s
q̇₂ = -0.1 rad/s
```

那么：

```text
[
  ẋ
  ẏ
]
=
[
  -1  -1
   1   0
]
[
   0.2
  -0.1
]
```

逐行相乘：

```text
ẋ = (-1)×0.2 + (-1)×(-0.1) = -0.1 m/s
ẏ =   1 ×0.2 +   0 ×(-0.1) =  0.2 m/s
```

因此末端此刻向左、向上运动：

```text
ṗ = [-0.1, 0.2]ᵀ m/s
```

不要只盯着计算。按列解释更加直观：

- 关节 1 单独转动贡献 `0.2×[-1,1]ᵀ`；
- 关节 2 反向转动贡献 `-0.1×[-1,0]ᵀ`；
- 两份速度相加，得到最终末端速度。

## 9. 现在进入第二个问题：末端力如何变成关节力矩

先区分“力”和“力矩”。

- 力可以理解成直着推或拉，单位是牛顿 `N`；
- 力矩可以理解成让关节发生转动的作用，单位是牛顿米 `N·m`。

假设有人在末端施加一个力：

```text
F =
[
  Fₓ
  Fᵧ
]
```

这个力会试图带动两个关节转动。我们想求它分别对关节 1、关节 2 产生多大的力矩：

```text
τ =
[
  τ₁
  τ₂
]
```

答案是：

```text
τ = JᵀF
```

但先不要背。下面从两个角度说明它为什么必然是雅可比的转置。

---

## 10. 第一种解释：每个关节分别看力臂

你推门时已经体验过力矩：

- 在门把手处横着推，很容易把门推开；
- 靠近门轴推，就很费劲；
- 对着门轴方向推，即使用力很大，门也不容易转。

一个力对某关节产生多大转动效果，取决于：

1. 力有多大；
2. 施力点离关节多远；
3. 力的方向是否善于让它绕关节转动。

在二维平面中，如果末端相对某关节的位置是：

```text
r = [rₓ,rᵧ]ᵀ
```

末端受到的力是：

```text
F = [Fₓ,Fᵧ]ᵀ
```

那么这个力绕该关节产生的力矩是：

```text
τ = rₓFᵧ - rᵧFₓ
```

把它换一种排列方式：

```text
τ = [-rᵧ, rₓ]
    [ Fₓ      ]
    [ Fᵧ      ]
```

注意 `[-rᵧ,rₓ]ᵀ` 是什么：它正是前面说的、末端绕这个关节运动时的切线方向，也就是这个关节对应的雅可比列。

因此：

```text
τ₁ = J₁ᵀF
τ₂ = J₂ᵀF
```

把两个关节的结果上下排起来：

```text
[
  τ₁
  τ₂
]
=
[
  J₁ᵀ
  J₂ᵀ
]
F
```

而：

```text
[
  J₁ᵀ
  J₂ᵀ
]
= Jᵀ
```

所以自然得到：

```text
τ = JᵀF
```

这不是为了让矩阵尺寸凑得上而随便加了一个转置。雅可比每一列本来描述“这个关节的转动会让末端朝哪里运动”，同一列与末端力做方向匹配后，恰好得到“这个力有多大程度会推动该关节转动”。

### 一个很重要的直觉

如果一个关节转动时，末端会沿某个方向移动，那么沿这个方向施加末端力，就最容易推动这个关节。

反过来，如果末端力完全垂直于该关节能够造成的末端速度方向，那么这个力不会通过该运动方向对关节做功，对应的关节力矩贡献就是零。

雅可比的列描述运动方向；同一个方向也决定力对关节的作用效率。

---

## 11. 第二种解释：微小位移中的做功必须相同

这一种解释更普遍，也解释了为什么任何复杂机械臂仍然使用 `Jᵀ`。

### 11.1 什么是功

先看直线运动。沿力的方向移动一小段距离，力所做的微小功是：

```text
微小功 = 力 × 沿力方向的微小位移
```

在二维中写成：

```text
δW = Fₓδx + Fᵧδy
```

写成向量形式：

```text
δW = Fᵀδp
```

其中：

```text
δp = [δx,δy]ᵀ
```

对旋转关节来说：

```text
微小功 = 力矩 × 微小转角
```

两个关节合起来：

```text
δW = τ₁δq₁ + τ₂δq₂ = τᵀδq
```

### 11.2 末端位移与关节位移由雅可比连接

关节轻微转动 `δq` 时，末端产生的微小位移是：

```text
δp = Jδq
```

这与速度关系 `ṗ=Jq̇` 完全同源，只是把“每秒的变化”换成了“一次非常小的变化”。

### 11.3 同一次作用，不能凭空多出或少掉一份功

在理想的刚性机械结构中，同一次非常小的运动：

```text
从末端这一侧计算的功 = 从关节这一侧计算的功
```

因此：

```text
τᵀδq = Fᵀδp
```

再把 `δp=Jδq` 代进去：

```text
τᵀδq = FᵀJδq
```

右边可以重新加括号：

```text
FᵀJδq = (JᵀF)ᵀδq
```

于是：

```text
τᵀδq = (JᵀF)ᵀδq
```

无论两个关节接下来选择怎样的微小转角 `δq`，等式都应该成立。那么前面乘着 `δq` 的两组关节力矩必须相同：

```text
τ = JᵀF
```

这就是常说的**虚功原理**。这里的“虚”不是虚假，而是假想一个满足机械结构关系的无穷小位移，用它检查两侧做功是否一致。

如果你觉得最后几步矩阵变形仍然抽象，可以暂时记住更朴素的版本：

> 末端的力通过机械结构传到关节以后，同一小段运动从末端算出的功，必须等于从关节算出的功。雅可比已经规定了两边位移怎样对应，因此力的对应关系只能是雅可比转置。

## 12. 为什么是转置，而不是逆矩阵

很多人第一次会想：

```text
既然 J 把关节速度变成末端速度，
把末端力变回关节力矩是不是应该用 J⁻¹？
```

不是。原因是力并不是“反向播放的速度”。

速度映射关心的是：

```text
关节怎样动 → 末端怎样动
```

力映射关心的是：

```text
末端的力 → 对每个关节做功的能力
```

后者必须保持功率或微小功，所以使用转置。

从矩阵形状也能看出来。假设机械臂有 `n` 个关节，末端只考虑二维位置：

```text
J 的形状：2×n
q̇ 的形状：n×1
ṗ 的形状：2×1
```

速度关系是：

```text
(2×1) = (2×n)(n×1)
```

而末端力是 `2×1`，我们要得到 `n×1` 个关节力矩，因此：

```text
Jᵀ 的形状：n×2
```

正好有：

```text
(n×1) = (n×2)(2×1)
```

更重要的是，`JᵀF` 不要求 `J` 是方阵，也不要求它可逆。三关节、七关节甚至更多关节的机械臂，都可以用同一个关系。

只有在反过来问“已知关节力矩，等效末端力是什么”时，才可能在特定条件下遇到逆转置；而且在冗余或奇异情况下，答案可能不唯一，不能随手写成一个普通逆矩阵。

## 13. 用同一个姿势完整算一次力矩

继续使用前面的姿势：

```text
l₁ = 1 m
l₂ = 1 m
q₁ = 0°
q₂ = 90°
```

已经算出：

```text
J =
[
  -1  -1
   1   0
]
```

因此：

```text
Jᵀ =
[
  -1   1
  -1   0
]
```

现在有人在末端施加一个水平向右的力：

```text
F =
[
  10 N
   0 N
]
```

那么这个外力对关节产生的力矩是：

```text
τ = JᵀF
```

```text
[
  τ₁
  τ₂
]
=
[
  -1   1
  -1   0
]
[
  10
   0
]
=
[
  -10
  -10
] N·m
```

两个负号表示这个向右的力会让两个关节产生顺时针转动趋势。

从几何上也很好检查：此时末端在 `(1,1)`，水平向右推它，会同时绕关节 1 和关节 2 顺时针转动。

再试一个竖直向上的力：

```text
F =
[
   0 N
  10 N
]
```

计算得到：

```text
τ =
[
  10
   0
] N·m
```

为什么第二关节力矩是零？因为第二段此时竖直，向上的力正好沿着第二段指向关节 2，没有绕关节 2 的力臂，所以不会推动第二关节旋转。

这与推门时“朝着门轴方向用力，门却不转”是同一个道理。

## 14. 最容易混乱的正负号问题

`τ=JᵀF` 中的 `F` 到底是谁对谁的力，必须先说明。

### 情况 A：外界对机械臂末端施加力

如果 `F` 表示“外界作用在机械臂末端上的力”，那么：

```text
τ_external = JᵀF
```

表示这个外力对各关节造成的力矩。

如果电机想让机械臂静止不动，在暂时忽略重力等其他作用时，就需要给出相反的力矩去抵消：

```text
τ_motor = -JᵀF
```

### 情况 B：机械臂想对外界施加力

如果你说“我希望机械臂末端向墙施加一个向右的力”，那么墙会根据作用与反作用，对机械臂施加一个向左的力。

这时到底写正号还是负号，取决于公式中的 `F` 被定义成：

- 机械臂对墙的力；还是
- 墙对机械臂的力。

不同书籍和软件可能采用不同约定，所以不要孤立地争论正负号。先画出力箭头，明确“这个力作用在哪个物体上”，再代公式。

真正不会变的是：

> 对机械臂末端实际施加的那个力，通过 `Jᵀ` 得到它对关节造成的力矩；电机若要静态抵消它，应施加反方向力矩。

## 15. 再用功率检查一次

速度关系：

```text
ṗ = Jq̇
```

力矩关系：

```text
τ = JᵀF
```

末端瞬时功率是：

```text
P_endpoint = Fᵀṗ
```

关节瞬时功率是：

```text
P_joint = τᵀq̇
```

把两个映射代进去：

```text
P_endpoint
= FᵀJq̇
= (JᵀF)ᵀq̇
= τᵀq̇
= P_joint
```

所以 `J` 与 `Jᵀ` 像一对配套齿轮：

- `J` 负责让两侧的运动对应；
- `Jᵀ` 负责让两侧的力与力矩对应；
- 它们一起保证理想传动中不会凭空创造功率。

这也能帮助检查单位：

```text
关节速度：rad/s
雅可比中的长度项：m/rad
末端速度：m/s
```

```text
末端力：N
雅可比转置中的长度项：m/rad
关节力矩：N·m
```

弧度通常作为无量纲量处理，因此最终单位正确。

## 16. `JᵀF` 不等于电机在任何情况下的全部力矩

这是非常重要的使用边界。

`JᵀF` 只告诉我们：

> 某个末端力对应怎样的关节力矩作用。

真实机械臂运动时，电机还可能需要处理：

- 连杆自身重量；
- 让连杆加速所需的作用；
- 关节摩擦；
- 其他位置受到的外力；
- 减速器和结构带来的影响。

因此，不应该看到期望末端力以后，就在所有场景里直接把 `JᵀF` 当成完整电机命令。

在非常缓慢、暂时忽略重力和摩擦的简单静态问题中，它可以近似代表需要平衡的主要力矩；在快速运动或复杂机器人中，它通常只是完整力矩关系中的一部分。

这不影响 `JᵀF` 本身成立，只是提醒我们不要让一个局部关系承担整个动力学问题。

## 17. 一个顺便就能看懂的现象：手臂伸直时为什么特殊

让机械臂完全水平伸直：

```text
q₁ = 0°
q₂ = 0°
```

代入雅可比：

```text
J =
[
  0       0
  l₁+l₂   l₂
]
```

观察第一行：不论两个关节怎样给出瞬时角速度，都会得到：

```text
ẋ = 0
```

这符合直觉：手臂已经完全伸直，只靠此刻的旋转运动，末端瞬间只能上下移动，不能继续沿手臂方向向外移动。

此时雅可比的两列都竖直，原本两个关节可以组合出的二维瞬时运动方向，只剩一个独立方向。这就是**奇异姿势**最直观的例子。

但即使在这个姿势，`τ=JᵀF` 仍然可以计算外力造成的关节力矩。只是不能随便把 `J` 求逆，用末端速度反算关节速度。

例如沿手臂方向向内或向外的力，在理想完全伸直的瞬间不会绕两个关节产生力矩，而主要表现为沿连杆方向的挤压或拉伸。这个信息同样会被 `JᵀF` 正确表达出来。

## 18. 把整条逻辑压缩成一条线

### 位置关系

先根据几何投影得到：

```text
x = l₁cos(q₁) + l₂cos(q₁+q₂)
y = l₁sin(q₁) + l₂sin(q₁+q₂)
```

### 对关节角求偏导

把四个敏感程度排成表：

```text
J =
[
  ∂x/∂q₁  ∂x/∂q₂
  ∂y/∂q₁  ∂y/∂q₂
]
```

### 得到运动映射

```text
ṗ = Jq̇
```

雅可比把关节速度变成末端速度。

### 保持微小功或功率一致

```text
τᵀδq = Fᵀδp
δp = Jδq
```

代入后得到：

```text
τ = JᵀF
```

雅可比转置把末端力变成这个力对各关节造成的力矩。

这就是整篇讲义最核心的因果链。

## 19. 不背公式时，应该记住什么

如果几天后忘记了矩阵的具体样子，只要还记得下面五点就足够重新推出来：

1. 末端位置来自每段连杆在 `x`、`y` 方向投影的相加。
2. 雅可比就是末端坐标分别对各关节角的偏导数表。
3. 雅可比的第 `i` 列表示只转第 `i` 个关节时，末端的瞬时速度方向和大小。
4. `ṗ=Jq̇` 是运动关系，`τ=JᵀF` 是与它保持做功一致的力关系。
5. 若 `F` 是外界对机械臂的力，电机为了静态抵消它通常要给相反方向的力矩。

最值得形成的直觉是：

> 一个关节怎样让末端运动，同一个几何关系也决定末端的力怎样推动这个关节。

## 练习答案

### 答案 1

第二段相对世界的角度：

```text
q₁+q₂ = 90°-90° = 0°
```

第一段竖直向上，第二段水平向右，因此：

```text
(x,y) = (1,2)
```

### 答案 2

此时第二段水平向右，绕关节 2 逆时针转动时，末端瞬间向上，所以雅可比第二列应指向 `y` 正方向。

代入也能得到：

```text
J₂ =
[
  -l₂sin(0°)
   l₂cos(0°)
]
=
[
  0
  1
]
```

### 答案 3

先计算整个雅可比：

```text
J =
[
  -2  0
   1  1
]
```

所以：

```text
Jᵀ =
[
  -2  1
   0  1
]
```

外力造成的关节力矩：

```text

= JᵀF
=
[
  -2  1
   0  1
]
[
  0
  5
]

[
  5
  5

```

### 答案 4

若只考虑这个外力，电机为了保持静止，需要施加反方向力矩：

```text
τ_motor = [-5,-5]ᵀ N·m
```

真实机械臂还需要同时补偿重力等其他作用。
